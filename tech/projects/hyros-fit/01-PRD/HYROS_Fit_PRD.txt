2.1 产品背景
    现有健身App存在明显痛点：
    - Keep类App：适合新手，缺乏进阶计划管理
    - 训记/Strong：手动录入繁琐，无AI导入功能
    - 备忘录/Excel：无法结构化追踪，无数据看板

    核心用户痛点："我有完整的训练计划，但没有一个App能帮我
    方便地导入、按日历执行、自动追踪进度"

2.2 产品定位
    名称: HYROS Fit
    Slogan: 计划即执行，打卡即进步
    定位: 面向有结构化训练计划的进阶健身者的计划管理+执行工具
    核心价值: AI计划导入 + 日历打卡 + 数据看板，三位一体化

2.3 目标用户画像

    【主要用户: 结构化训练者】
    年龄: 20-35岁
    性别: 男性为主(70%)，女性(30%)
    训练经验: 6个月以上，有明确分化计划
    训练频率: 每周4-6次
    痛点: 
      - 计划散落在备忘录/截图/Excel中
      - 每次训练要翻找计划，不方便
      - 无法直观看到训练进度和力量增长
      - 手动记录重量次数太麻烦
    设备: 安卓手机(主要)，部分iOS
    使用场景: 健身房训练时实时打卡，训练后查看统计

    【次要用户: 计划制定者】
    健身教练、健身博主
    需求: 为客户制定计划，通过App分享，客户直接执行

4.1 模块一: 计划管理 (Plan Management)

4.1.1 功能: 创建计划

    入口: 首页"+"按钮 -> "新建计划"

    创建流程:
    Step 1: 基础信息
      - 计划名称 (默认: "我的训练计划")
      - 计划周期 (4周/8周/12周/自定义周数)
      - 训练分化 (3分化/4分化/5分化/6分化/自定义)
      - 每周训练天数 (自动根据分化推荐)

    Step 2: 设置训练日
      - 选择每周哪几天训练 (多选: 周一到周日)
      - 每天训练重点 (如: 胸+三头/背+二头/腿)
      - 每天训练时长预估 (30min/60min/90min/自定义)

    Step 3: 添加动作 (核心交互)
      - 搜索动作库 (支持拼音/中文/英文搜索)
      - 动作分类筛选 (胸部/背部/腿部/肩部/手臂/腹部/有氧/全身)
      - 添加动作后设置:
        * 组数 (1-10组)
        * 次数 (范围如8-12，或固定值)
        * 重量 (可选，首次训练可不填)
        * 休息时长 (30s/45s/60s/90s/2min/3min/自定义)
        * 备注 (如"腰带保护"、"控制离心3秒")
      - 拖拽排序: 长按动作项上下拖拽调整顺序
      - 超级组标记: 两个动作间点击"链接"图标，标记为超级组
        * 超级组显示: 动作A -> 动作B (超级组)
        * 超级组休息: 完成两个动作后才计时

    Step 4: 预览与保存
      - 周视图预览所有训练日
      - 确认后生成日历计划
      - 提示: "计划已生成，共X周，Y次训练"

    异常处理:
      - 未添加任何动作: 提示"请至少添加一个动作"
      - 同一天添加超过15个动作: 提示"动作过多，建议控制在12个以内"

4.1.2 功能: AI导入计划 (核心差异化功能)

    入口: 首页"+"按钮 -> "AI导入计划"

    支持导入方式 (Tab切换):

    【方式A: 文本粘贴导入】
      - 输入框: 多行文本输入，支持粘贴长文本
      - 示例按钮: 点击显示示例格式，帮助用户理解
      - 识别按钮: "开始识别"
      - 识别结果预览:
        * 左侧: 原始文本
        * 右侧: 解析结果 (可编辑修正)
        * 未识别项高亮显示，提示手动修正
      - 确认导入 -> 生成计划

    【方式B: 截图/拍照导入】 (P2)
      - 选择图片: 相册选择或直接拍照
      - AI识别进度: "正在识别..." 进度条
      - 识别结果: 同文本导入，显示解析结果
      - 手动修正: 点击未识别区域手动输入

    【方式C: Excel/CSV导入】
      - 文件选择器
      - 列映射: 选择哪列是"动作名"/"组数"/"次数"等
      - 预览后导入

    AI识别规则 (NLP解析逻辑):

    输入示例:
    周一 胸+三头+腹+有氧
    平板杠铃卧推 4组x8-10次 休息90s
    上斜哑铃卧推 4组x10-12次 休息75s
    双杠臂屈伸 3组x10-12次

    解析逻辑:
    1. 日期识别: "周一" -> day_of_week=1
    2. 训练主题: "胸+三头+腹+有氧" -> focus字段
    3. 动作名匹配: 
       "平板杠铃卧推" -> 动作库模糊匹配 "杠铃卧推" -> ID: BP001
       置信度>80%直接匹配，<80%提示用户确认
    4. 组数识别: "4组" -> sets=4
    5. 次数识别: "8-10次" -> reps_min=8, reps_max=10
       "10次" -> reps_min=10, reps_max=10
    6. 休息识别: "休息90s" -> rest=90
       未识别时默认: 力量动作60s，复合动作90s，大项120s
    7. 碳水日识别 (针对用户计划):
       行首含"高碳" -> carb_day="high"
       行首含"中碳" -> carb_day="medium"
       行首含"低碳" -> carb_day="low"

    未识别处理:
      - 动作名未匹配: 显示"未识别动作: XXX"，提供"添加到动作库"或"选择相似动作"
      - 数字缺失: 组数默认3组，次数默认10次，休息默认60s
      - 日期缺失: 标记为"未分配日期"，用户手动分配到周几

4.1.3 功能: 计划模板库

    入口: 首页"+"按钮 -> "从模板创建"

    模板分类:
    - 增肌系列: PPL 6天/上下肢 4天/5x5 力量基础/施瓦辛格计划
    - 减脂系列: HIIT 3天/全身循环/碳循环配合
    - 力量系列: 力量举专项/奥林匹克举重基础
    - 特色系列: HYROS备赛计划/女性塑形/居家哑铃

    模板详情页:
    - 计划介绍 (文字+示意图)
    - 周视图预览
    - 预计周期
    - 适用人群
    - "使用此模板"按钮 -> 可编辑后保存

    用户计划分享为模板:
    - 我的计划 -> 点击"分享为模板" -> 填写介绍 -> 审核后上架

4.1.4 功能: 计划编辑与管理

    我的计划列表:
    - 显示所有计划 (进行中/已结束/草稿)
    - 每个计划显示: 名称/周期/进度百分比/下次训练日期

    计划详情页:
    - 周视图/日视图切换
    - 编辑模式: 点击某天进入编辑，可增删改动作
    - 全局替换: 替换整个计划中某个动作 (如所有"杠铃卧推"改为"哑铃卧推")
    - 复制功能: 复制某天的训练到另一天
    - 删除计划: 二次确认
    - 导出计划: 生成文本/图片/Excel

4.1.5 功能: 计划执行状态管理

    计划生命周期:
    草稿 -> 进行中 -> 已完成/已暂停

    状态规则:
    - 进行中: 有未来训练日未执行
    - 已完成: 所有训练日已执行或跳过
    - 已暂停: 用户手动暂停，日历不再显示
    - 草稿: 创建中未保存完整

    多计划支持:
    - 可同时存在多个"进行中"计划
    - 日历上显示不同计划的颜色标记
    - 当日有多个计划时，选择执行哪个

    - 两组都完成后才启动休息计时
    - 进度显示: "超级组 1/3"

    动作操作:
    - 左滑动作 -> 快捷操作: 替换/跳过/添加备注
    - 点击"替换" -> 搜索相似动作替换
    - 点击"跳过" -> 记录原因 (伤病/器械被占/时间不够/其他)
    - 点击"笔记" -> 弹出输入框记录感受

    语音输入 (P2):
    - 长按输入框 -> 语音输入
    - "卧推八十公斤八次" -> 解析为 weight=80, reps=8

    底部按钮状态:
    - 训练中: "完成今日训练 (X/Y动作)"
    - 全部完成: "训练完成！查看总结"
    - 点击后: 弹出训练总结页

4.2.4 功能: 补签

    触发条件:
    - 日历点击过去未完成的日期
    - 训练界面点击"补签"按钮

    补签流程:
    1. 选择日期 -> 显示当天计划
    2. 选择补签方式:
       □ 按原计划执行并记录 (进入训练界面)
       □ 标记为已完成 (不记录具体数据)
       □ 标记为休息日 (调整后续计划顺延)
       □ 跳过 (记录原因)
    3. 如选择"顺延": 询问"后续所有计划顺延1天？"
    4. 确认后更新日历

4.2.5 功能: 休息日与调整

    主动休息:
    - 长按未来日期 -> "标记为休息日"
    - 自动调整后续计划 (询问是否顺延)

    - 训练日前一晚 21:00 推送: "明天练胸，记得准备"
    - 训练日早起 6:00 推送: "早安！今日训练计划已就绪"

4.4 模块四: AI智能 (AI Features)

4.4.1 功能: AI计划识别 (P1)

    技术方案:
    - 前端: OCR使用Google ML Kit (端侧，无需联网)
    - 后端: NLP解析使用自研规则引擎 + 云端LLM备用
    - 动作库: 本地缓存常用500动作，云端扩展2000+

    识别准确率目标:
    - 动作名识别: >90%
    - 组数/次数识别: >95%
    - 日期识别: >95%
    - 整体可用率: >85% (用户少量修正即可使用)

4.4.2 功能: AI智能建议 (P2)

    建议触发场景:

    【进度停滞检测】
    - 检测逻辑: 某动作连续3次训练重量或次数无进步
    - 建议内容: 
      "检测到卧推连续3次停滞在80kg，建议：
       1. 减载至72.5kg，做3组x12次 (容量积累周)
       2. 增加辅助训练: 窄距卧推 3组x10次
       3. 检查卧推技术: 肩胛下沉/起桥/腿驱"

    【容量过载检测】
    - 检测逻辑: 本周容量较上周增长>30%
    - 建议: "本周容量增长35%，注意恢复，建议增加休息日或降低强度"

    【训练频率优化】
    - 检测逻辑: 某部位每周训练容量占比<10%
    - 建议: "腿部训练占比仅8%，建议增加1次腿部训练"

    【休息不足提醒】
    - 检测逻辑: 连续训练5天无休息
    - 建议: "已连续训练5天，建议明天安排休息或低强度恢复"

4.4.3 功能: AI计划生成 (P2)

    对话式生成:

    用户输入: 
    "我23岁男，179cm，147斤，每周6练，早上6点半，
     有健身房，想减脂增肌"

    AI追问 (如需):
    "您的训练经验如何？
     □ 新手(<6个月) □ 进阶(6个月-2年) □ 高级(2年+)"

    AI生成:
    "基于您的信息，推荐以下计划：
     【HYROS 6分化增肌减脂计划】
     周期: 16周 | 每周6练 | 每次60-75min
     分化: 胸/背/肩/腿/手臂/腿(腘绳)
     特点: 碳循环配合，早起训练优化

     [预览计划] [直接使用] [调整细节]"


4.5 模块五: 基础支撑 (Infrastructure)

4.5.1 用户系统
    - 注册: 手机号/邮箱/微信授权
    - 登录: 密码/验证码/生物识别
    - 个人资料: 昵称/头像/身高/体重/训练目标
    - 隐私设置: 数据公开/仅自己/好友可见

4.5.2 动作库

    - 每个动作包含:

      * 分类 (部位/类型)
      * 难度 (初级/中级/高级)
      * 器械需求 (杠铃/哑铃/器械/自重)

    - 导出: 支持导出为Excel/CSV/文本

4.5.5 设置
    - 单位: 公制(kg/cm) / 英制(lbs/ft)
    - 声音: 计时器音效/语音播报开关
    - 震动: 开关
    - 主题: 深色/浅色/跟随系统
    - 计时器默认时长: 全局设置/按动作类型设置
    - 数据管理: 清除缓存/导出/删除账号

    文字:
    - 主文字: 白色 #FFFFFF
    - 次文字: 灰白 #B0B0B0
    - 禁用: 灰色 #757575

6.3 字体

    - 中文: Noto Sans SC
    - 英文标题: Montserrat Bold
    - 字号层级: 标题24sp/副标题18sp/正文16sp/辅助14sp

6.4 图标风格
    - 线性图标 (2px描边)
    - 填充状态用面性图标
    - 统一圆角风格

    - 力竭 (Failure): 无法完成规定次数
    - 渐进超负荷 (Progressive Overload): 逐步增加训练负荷
