HYROS Fit

配置上线手册 v1.0 | MVP 版本

一、环境准备

1
Node.js ≥ 18

从 nodejs.org 下载 LTS 版本。验证：

node -v
npm -v
2
Expo CLI

全局安装 Expo CLI：

npm install -g expo-cli
3
Android 环境（二选一）
  • 真机调试：开启手机「开发者选项」→「USB 调试」，用数据线连接电脑。推荐，响应最快。
  • Android Studio 模拟器：安装 Android Studio，创建虚拟设备（API 33+，推荐 Pixel 系列）。
4
Git（可选）

用于版本管理。

git --version

二、项目安装步骤

1
进入项目目录
cd hyros-fit/src
2
安装依赖
npm install
首次安装可能需要 2-5 分钟，取决于网络环境。
3
验证安装
npx expo --version

三、本地调试运行

1
启动开发服务器
npx expo start
会自动打开 Metro Bundler 网页控制台。
2
连接到设备
  • 真机：手机安装「Expo Go」App（Google Play 下载），扫描 Metro 页面二维码。
  • 模拟器：在 Metro 页面点击 "Run on Android device/emulator"。
3
热重载

修改代码后自动刷新。按 R 强制重载，Ctrl+M 打开开发者菜单。

四、打包 APK

方式 A：EAS Build（推荐，云端打包）

1
安装 EAS CLI
npm install -g eas-cli
2
登录 Expo 账号
eas login
3
构建 APK
eas build -p android --profile preview
首次构建约 10-15 分钟。完成后会提供下载链接。

方式 B：本地打包（需 Android SDK）

npx expo prebuild -p android
cd android
./gradlew assembleRelease
本地打包需要配置 Android SDK 和签名密钥，流程较复杂。MVP 阶段推荐使用 EAS Build。

五、真机安装方法

  1. 通过 USB 将 APK 传输到手机，点击安装。
  2. 或发送到手机微信/QQ，在聊天中点击安装。
  3. 若提示「未知来源」，前往设置 → 安全 → 允许未知来源应用安装。
  4. 安装完成后，桌面出现「HYROS Fit」图标，点击打开。

六、常见问题排查

问题解决方案
Metro 启动失败检查 8081 端口是否被占用：
npx expo start --port 8082
手机无法连接确保手机和电脑在同一 WiFi。
真机用 USB 更稳定。
SQLite 报错Expo SQLite 在部分模拟器上有兼容问题。
建议用真机调试。
Expo Go 白屏清除 Expo Go 缓存，或重新扫描 QR。
EAS Build 排队久Expo 免费队列可能有延迟。
可购买 Priority Build。
