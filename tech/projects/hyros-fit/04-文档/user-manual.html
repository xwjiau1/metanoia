HYROS Fit

产品初版说明书 v1.0 | MVP 版本

一、产品简介

HYROS Fit 是一款专为力量训练爱好者设计的健身记录 App。核心定位：轻量化、离线可用、单手操作友好。

适合谁用：

  • 健身房力量训练者，需要记录重量和次数
  • 希望按训练计划执行，不想每次临时想动作
  • 关注训练容量和连续打卡习惯
  • 不想依赖云端，数据保存在本地
MVP 版本完全离线运行，无需注册真实手机号，无需联网权限。

二、快速开始

  1. 首次打开：看到登录页，点击「还没有账号？去注册」。
  2. 注册账号：输入用户名、密码（至少4位）、昵称。全部本地存储。
  3. 进入首页：问候语 + 今日训练卡片 + 快捷入口。
  4. 创建第一个计划：点击「+ 新建训练计划」，按向导完成。
  5. 开始训练：从日历或训练页进入当日训练日，点击「训练打卡」。

三、功能说明

3.1 如何创建训练计划

路径：底部导航「训练」→ 右上角 + 号

  1. 填写计划名称，如「增肌期A」。
  2. 选择分化模板：
    • 全身训练（3天/周）
    • 上肢/下肢分化（4天/周）
    • 推/拉/腿分化（6天/周）
    • 经典五分化（5天/周）
    • 自定义（7天）
  3. 调整训练日：可修改名称、切换休息日。
  4. 添加动作：从内置 50+ 动作库中选择，按肌群分类浏览。
  5. 完成：计划出现在「训练」列表中。
创建后点击计划卡片，选择「设为活跃」才会在首页和日历中显示。

3.2 如何查看日历和执行训练

路径：底部导航「日历」

  • 日历中用绿色圆点标记已训练日期。
  • 点击任意日期查看当日训练记录（如有）。
  • 「今日安排」显示当前活跃计划今日应练内容。
  • 点击今日安排卡片直接进入打卡界面。

3.3 如何打卡记录重量和次数

路径：训练打卡界面

  1. 每个动作默认显示计划设定的组数。
  2. 点击「添加组」可追加额外组。
  3. 在「重量」和「次数」输入框填入实际数据（支持小数重量）。
  4. 完成一组后点击右侧圆圈标记「完成」。
  5. 完成组会变为绿色对勾。
首次输入某动作的重量/次数后，下次会自动预填上次数据，减少重复输入。

3.4 如何使用计时器

路径：打卡界面点击任意动作右侧的 ⏱ 图标，或从任意界面导航到计时器。

  • 默认 60 秒组间休息。
  • 点击播放/暂停控制。
  • ±10s 快速调整。
  • 预设快捷键：30s / 60s / 90s / 120s / 180s。
  • 倒计时结束自动震动提醒。

3.5 如何查看统计数据

路径：底部导航「统计」

  • 核心指标：总训练次数、总容量(kg)、连续打卡天数、本月训练次数。
  • 本周容量趋势：柱状图展示最近7天训练容量。
  • 里程碑：1次、10次、30次、50次、100次训练成就徽章。

四、数据管理

备份

MVP 版本数据存储在设备本地 SQLite 数据库中（路径：/data/data/com.hyros.fit/databases/）。

MVP 阶段暂不提供自动云备份。建议定期导出数据库文件保存到安全位置。

恢复

若更换设备，需手动迁移数据库文件。后续版本将支持导出/导入 JSON 备份。

数据保留

  • 卸载 App 会清除所有本地数据。
  • 更新 App 不影响已有数据。

五、注意事项和 FAQ

Q: 需要联网吗？

完全不需要。所有功能离线可用。

Q: 支持 iOS 吗？

MVP 版本优先保证 Android。Expo 项目天然跨平台，iOS 构建需 Mac + Xcode，后续可扩展。

Q: 动作库只有 50 个，不够用？

MVP 覆盖胸/背/腿/肩/手臂/腹/有氧七大类常见动作。后续版本支持自定义添加动作。

Q: 忘记密码怎么办？

MVP 阶段密码仅本地存储，无找回机制。建议记录在安全位置。

Q: 可以同时有多个活跃计划吗？

不能。同一时间只能有一个活跃计划，但可保存多个计划并随时切换。

Q: 休息日需要打卡吗？

不需要。休息日无需任何操作，连续打卡天数只统计有训练记录的日子。

Q: 容量是怎么算的？

容量 = 重量(kg) × 次数 × 完成组数。只做记录不标记完成不计入容量。
