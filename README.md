## 公司记忆系统

本项目采用分层记忆管理：

- **公司级记忆** → `wenner/MEMORY.md`（长期保留）
- **部门记忆** → `tech/memory/` / `design/memory/`（30天保留）
- **日常流水** → 各 `diary/` 或 `memory/`（3天保留）
