# Nike 心动设计拆解

## 第一眼感受

Nike 的网站像是一本翻到运动特辑的高端杂志。巨大的大写 Futura 标题（`display-campaign`: 96px, uppercase）直接压在全幅摄影之上，黑白分明的界面语言让产品摄影成为绝对的统治者。这是一个"运动编辑"的世界——不是典型的电商网格，而是"campaign first, commerce second"。按钮是 pill 形的，但有一种运动员的利落感；搜索框是 pill 形的，但有一种工具的精确感。整个界面散发着一种自信到近乎傲慢的能量："我们不需要花哨的装饰，我们的产品本身就是艺术。"

## 色彩策略

**主色：Nike Black `#111111`**

Nike 的"主色"就是黑色。黑色是 Nike 的品牌灵魂——从 Swoosh 到鞋盒到店面，黑色是 Nike 的永恒底色。在网页上，黑色是 CTA 按钮、是文字、是过滤器的 active 状态、是活动贴片的背景。当 Nike 想要表达任何重要信息时，它使用黑色。

**辅助色：Pure White `#ffffff` 和 Soft Cloud `#f5f5f5`**

白色是黑色的平等搭档——它承载页面背景、承载产品图片的舞台。`#f5f5f5`（Soft Cloud）是产品卡片图片的背景色，它让产品图片在一个微妙的"灰色舞台"上展示，比纯白更柔和。

**语义色：**
- **Sale Red**（`#d30005`）：唯一的"情绪色"，用于折扣价格。这是整个零售界面中唯一出现红色的地方。
- **Success Green**（`#007d48`）：用于成功状态。

**情绪定位：运动能量 + 编辑权威**。黑白是运动摄影的经典语言——从《体育画报》到 Nike 自己的广告，黑白让色彩留给运动本身。

## 排版策略

**字体选择逻辑：**
- **Campaign Display**：Nike Futura ND — 定制的 Futura 版本，用于巨大的大写标题。Futura 的几何感（圆形 'o'、三角形 'A'）传递了现代、运动、速度的感觉。大写 + 0.9 行高让标题有一种"压缩的能量"。
- **UI / Body**：Helvetica Now — 现代化的 Helvetica，为屏幕优化。Medium 字重（500）用于强调，Regular（400）用于正文。

**字号层级与呼吸感：**
- display-campaign: 96px / weight 500 / line-height 0.9 / uppercase
- heading-xl: 32px / weight 500
- body-md: 16px / weight 400 / line-height 1.5

**巨大的 display-campaign 是 Nike 的核武器**——96px 的大写标题直接压在摄影上，这种尺度和处理方式在电商界独一无二。它传递的不是"信息"，而是"宣言"。

**呼吸感：** Nike 的呼吸感来自"强对比"——巨大的标题与紧凑的正文之间形成强烈反差，产品图片与 UI chrome 之间形成强烈反差。这种"反差式呼吸"让页面充满张力。

## 空间策略

**留白节奏：** Nike 的留白是"编辑留白"——不像 Apple 那样奢侈，也不像 SaaS 那样紧凑。它的页面结构是：Campaign Hero（全幅摄影+大标题）→ 产品网格（紧凑但整齐）→ 运动专题 → 页脚。

**信息密度：** 中高密度。作为电商，Nike 需要展示大量 SKU，但它的产品网格极其整齐（基于 8px 的 spacing scale），给人一种"军队般的纪律感"。

**视觉焦点：** 产品摄影是唯一的彩色来源。Nike 的 UI chrome（导航、按钮、过滤器）全部是中性的黑白灰，所有色彩能量都留给产品图片本身。这是一个极其聪明的信息层级策略：产品 = 内容 = 色彩。

## 可借鉴到启明项目的点

1. **"摄影即色彩"的策略**：Nike 的 UI 没有装饰色，所有颜色来自产品摄影。如果你的产品本身有强烈的视觉属性（硬件、实体产品、图片内容），让 UI "无色"，让产品 "有彩"。

2. **大写标题的力量**：Nike Futura 的大写 96px 标题是品牌最强的视觉签名。启明项目可以在 Landing Page 或 Campaign 页面尝试超大尺寸的大写标题（全大写、letter-spacing 适度），效果极具冲击力。

3. **8px 网格的纪律美**：Nike 的整个 spacing system 基于 8px，这让所有元素之间有一种数学般的和谐。启明项目的设计系统应该以 4px 或 8px 为基底单位。

4. **中性 UI + 彩色内容的模式**：Nike 证明了电商界面可以没有装饰色——所有色彩来自产品。这为启明科技的产品展示页面提供了模板：UI 穿黑白，产品穿彩色。

5. **Pill 形状的运动感**：Nike 的所有按钮都是 pill 形（`rounded.full`），但配合大写的 Helvetica Now Medium，它们有一种"运动员的利落感"而非"Airbnb 的温馨感"。同样的几何形状，不同的字体和字重可以传达完全不同的情绪。
