# Linear 心动设计拆解

> 来源：awesome-design-md / linear.app
> 研究日期：2026-05-13
> 研究员：Mery（启明科技 CIO）

---

## 第一眼感受

**"像打开一台精心调校的精密仪器——暗色背景上，lavender 蓝色的光标在跳动。"**

Linear 是所有 SaaS 产品中「暗色美学」的巅峰。`#010102` 是这套系统中最深的底色，比纯黑更冷、更纯粹。唯一的色彩事件是 lavender 蓝 `#5e6ad2`，它只出现在品牌 mark、focus ring 和几个关键 CTA 上——从不滥用。

---

## 色彩策略

### 暗色层次（极致精密）
```
画布: #010102 (几乎纯黑，带一丁点暖)
表面 1: #0f1011 (卡片)
表面 2: #141516 (提升)
表面 3: #18191a (更高提升)
hairline: #23252a (边框)
```
四层暗色表面之间的差异极小（肉眼几乎难以分辨），但这正是「精密」的体现——每一层都有明确的语义。

### 文字层次（暗色上的亮度阶梯）
```
#f7f8f8 — 主文字（最亮）
#d0d6e0 — 次要
#8a8f98 — 柔和
#62666d — 第三级
```

### 品牌色（极度克制）
- `#5e6ad2` lavender 蓝 — 只用于：品牌 mark、focus ring、关键 CTA
- 从不作为背景色、从不作为大面积装饰
- 这种克制让每一次出现都「珍贵」

---

## 排版策略

### 字体：Linear 定制字体
- **Linear Display** — 展示标题，600-700 字重，大负字距
- **Linear Text** — 正文，400 字重，微负字距
- **Linear Mono** — 代码/数据，等宽

### 展示字号（惊人地大）
```
Display XL: 80px/600/-3.0px — 巨大但紧凑
Display LG: 56px/600/-1.8px
Headline: 28px/600/-0.6px
```

### 正文
```
Body: 16px/400/1.50/-0.05px — 微负字距增加紧凑感
Body SM: 14px/400/1.50 — 辅助信息
Caption: 12px/400 — 元数据
Eyebrow: 13px/500/0.4px — 小标题/标签
Mono: 13px/400 — 代码
```

---

## 空间策略

### 信息密度：高密度但有序
- Linear 的信息密度比 Vercel 高得多，但不像传统 dashboard 那样混乱
- 秘密在于「层级清晰」：暗色表面 + hairline 边框自然划分区域
- 不需要额外的分隔线或阴影

### 间距
```
xxs: 4px, xs: 8px, sm: 12px, md: 16px
lg: 24px, xl: 32px, xxl: 48px
section: 96px
```

### 卡片设计
- 背景：`#0f1011`（表面 1）
- 边框：`#23252a`（hairline）— 1px，极细
- 圆角：md (8px)
- 无阴影 — 在暗色背景下不需要阴影就能产生层级

---

## 可借鉴到启明项目的点

### 立即可用
1. **四层暗色表面系统**：只要暗色背景，就有「画布→表面1→表面2→表面3」的层级
2. **单色品牌色的克制使用**：选一个色，只用在最关键的地方（CTA、focus、brand mark）
3. **hairline 边框代替阴影**：暗色背景上，1px 细线比阴影更优雅
4. **高密度信息的层级管理**：不是靠间距，而是靠表面层级和文字亮度层级

### 中文适配
- Linear Display → MiSans / HarmonyOS Sans（同样是几何感）
- 负字距从 -3.0px 大幅缩减至 -0.03em（中文不能这么紧）
- 行高 1.5 对中文刚好，无需调整

### 适合启明的项目类型
- 数据 dashboard、项目管理、后台系统、开发者工具
- 任何需要「高密度信息 + 暗色沉浸」的产品
