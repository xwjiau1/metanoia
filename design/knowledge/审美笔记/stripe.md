# Stripe 心动设计拆解

## 第一眼感受

Stripe 的网站像是一本精装的金融科技杂志与一位极简主义画家的合作产物。最让你心动的不是某个单一元素，而是那个占据页面上方三分之一的**渐变网格**——奶油色、雪葩橙、薰衣草紫、电靛蓝、宝石红如雾气般水平流淌。这是 Stripe 的"品牌签名"：一种既技术又艺术的氛围，暗示"金融基础设施"可以很美。深海军色的文字（`#0d253d`）在白色画布上稳健地叙述，电靛蓝的按钮（`#533afd`）像一颗宝石点缀其间。

## 色彩策略

**主色：Electric Indigo `#533afd`**

Stripe 的靛蓝是一种"智能的紫蓝"——它带有紫色的创造力和蓝色的可信赖。在金融科技领域，蓝色是安全的默认选择，但 Stripe 通过向紫色偏移，获得了差异化。这个颜色在渐变网格中出现，也在 CTA 按钮中出现，形成首尾呼应。

**深海军 Ink：`#0d253d`**

Stripe 的文字不是黑色，而是深海军蓝。这是一种"金融的颜色"——比黑色更温和，比灰色更权威。海军蓝带有天然的"机构感"和"信任感"。

**渐变网格**：
奶油色（`#f5e9d4`）→ 雪葩橙 → 薰衣草紫 → 电靛蓝（`#533afd`）→ 宝石红（`#ea2261`）。这个渐变是 Stripe 的视觉锚点，它出现在几乎所有营销页面的顶部。

**情绪定位：金融的诗意 + 技术的美感**。渐变网格传递"创新""艺术""想象力"，深海军文字传递"稳重""可信""专业"，电靛蓝传递"行动""转化"。

## 排版策略

**字体选择逻辑：**
- **Display**：Sohne（Klim Type Foundry 出品）at weight 300（thin）。这是一个极具编辑感的排版选择——Thin weight + 负字间距（-1.4px 到 -0.2px）让标题有一种"高端杂志"的紧凑感和精致感。
- **正文**：Sohne 300 / 400，开启了 `ss01` 风格集（单层的 'a' 等变体），这是 Stripe 的排版签名。
- **数字/表格**：Sohne + `tnum`（tabular figures，等宽数字）。在金融数据中，数字对齐至关重要，`tnum` 确保所有数字宽度一致。

**字号层级与呼吸感：**
- display-xxl: 56px / weight 300 / line-height 1.03 / letter-spacing -1.4px
- display-xl: 48px / weight 300 / line-height 1.15 / letter-spacing -0.96px
- display-lg: 32px / weight 300 / line-height 1.1 / letter-spacing -0.64px

**字重 300（thin）是 Stripe 的排版灵魂**。在 56px 的字号下使用 300 字重，需要极高的字体质量（Sohne 做到了），效果是一种"精致的轻盈"——像是一张高质量的薄纸。

**呼吸感：** Sohne thin weight 的轻盈感 + 充足的行高（1.03-1.15）+ 负字间距 = 一种"编辑级"的排版呼吸感。Stripe 的标题看起来像是《The Economist》的排版——紧凑、精确、有文化感。

## 空间策略

**留白节奏：** Stripe 的页面分为三个垂直区域：渐变网格英雄区（上部 1/3）→ 白色功能说明区 → 深色产品 mockup 区。这种"三段式"节奏在每个页面重复，形成极强的品牌一致性。

**信息密度：** 中低密度。金融科技需要建立信任，而信任需要"空间"——拥挤的界面让人焦虑， spacious 的界面让人安心。

**视觉焦点：** 渐变网格是首先吸引目光的元素，然后是深海军标题，最后是电靛蓝 CTA。这三个焦点形成了完美的"视觉漏斗"。

## 可借鉴到启明项目的点

1. **渐变网格作为品牌签名**：Stripe 的渐变网格不是"装饰"，它是品牌的视觉 DNA。启明项目可以思考：我们是否有这样一个"一眼可识别"的视觉元素？可以是一个图案、一种纹理、一种动态效果。

2. **Thin weight 的高端感**：在 48-56px 的标题中使用 300 字重，可以创造出极其精致的"编辑感"。启明科技的 marketing 页面可以尝试这种"轻字重大字号"的策略。

3. **等宽数字（tnum）在数据场景的必要性**：如果你的产品涉及任何数据展示（金额、统计、表格），务必启用 `font-feature-settings: 'tnum'`。对齐的数字看起来专业 10 倍。

4. **"金融蓝"的重新定义**：Stripe 没有使用传统的"银行蓝"，而是创造了"深海军 + 电靛蓝"的组合。这传递了"我们是新一代金融"的信号。启明科技的 B2B 产品可以考虑是否需要一个"传统色的变体"来传递创新感。

5. **颜色温度的叙事性**：Stripe 的渐变网格从左到右是从暖（奶油橙）到冷（蓝紫红），这种温度变化本身就在讲述一个"从想法到实现"的故事。颜色序列可以叙事。
