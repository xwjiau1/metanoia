# Supabase 心动设计拆解

## 第一眼感受

Supabase 的界面给人一种"春天的技术文档"的感觉——纯白的画布上，一道清新的翡翠绿（`#3ecf8e`）像新叶般点缀其间。与其他开发者工具常用的蓝/黑/紫不同，Supabase 选择了绿色——大自然中最"生长""活力""清新"的颜色。界面上的产品截图（数据库表格、SQL 编辑器、日志流）像是一本技术杂志的内页：干净、清晰、有说服力。没有插画，没有装饰，只有产品本身在说话。

## 色彩策略

**主色：Emerald Green `#3ecf8e`**

Supabase 的翡翠绿是一个极其聪明的品牌色选择。在开发者工具的海洋中，蓝色是标准配置（AWS 蓝、Azure 蓝、Vercel 蓝），而绿色是"开源""生长""PostgreSQL"的隐喻。绿色也传递了"友好""可接近"的情绪——Supabase 是 Firebase 的开源替代，这种"草根""社区"的气质与绿色完美契合。

**Press 状态：`#24b47e`**（更深的翡翠绿）

按压状态的绿色更深，暗示"扎根""深入"。颜色变化方向是"向下扎根"而非"向上发光"，这是一种"沉稳"的设计语言。

**情绪定位：开源活力 + 技术清晰**。白色画布 = 透明、开放；翡翠绿 = 生长、社区；近黑文字 = 专业、精确。

## 排版策略

**字体选择逻辑：**
- **Display / UI**：Circular（Lineto 出品的几何人文无衬线体），fallback 到 Helvetica Neue。Circular 的特点是字母带有轻微的人文主义曲线（如双层的 'a'），在几何感和温暖感之间取得了完美的平衡。它不像 Futura 那样过于几何化，也不像 Helvetica 那样过于中性。
- **Code**：系统等宽字体栈（ui-monospace, Menlo, Monaco...）。

**字号层级与呼吸感：**
- display-xxl: 64px / weight 500 / line-height 1.1 / letter-spacing -1.92px
- display-xl: 48px / weight 500 / line-height 1.1 / letter-spacing -1.44px
- display-lg: 36px / weight 500 / line-height 1.15 / letter-spacing -0.72px
- display-md: 28px / weight 500 / line-height 1.2 / letter-spacing -0.42px

关键特征：**weight 500 贯穿所有 display 层级**，依靠字号和 letter-spacing 来建立层级。这创造了极其统一的视觉节奏。

**呼吸感：** 白色背景 + 灰色文字层级 + 绿色 accent = 极其清新的呼吸感。每个区块之间有明确的分隔（通常是 hairline 或 section spacing），信息密度适中。

## 空间策略

**留白节奏：** 白色画布上的留白是"干净的留白"。Supabase 的页面结构通常是大标题 → 产品截图 → 功能列表，每个部分之间有足够的呼吸空间。

**信息密度：** 中等。作为开发者工具，Supabase 需要在营销页面和技术文档之间找到平衡。它的 marketing 页面信息密度适中，产品截图本身承担了"可视化"的职责。

**视觉焦点：** 翡翠绿是唯一的"色彩事件"。按钮、标签、logo 点缀、状态指示——所有交互元素共享同一个绿色。用户的视线被自动引导到这些绿色元素上。

## 可借鉴到启明项目的点

1. **"单 chromatic 事件"策略**：Supabase 的整个页面几乎只有绿色是有彩色的，其余全是黑白灰。这种"单色策略"让品牌色极度突出。启明项目可以思考：我们的页面上有多少个"有彩色"？能否减少到 1-2 个？

2. **产品截图作为视觉资产**：Supabase 的产品截图是其设计系统中最重要的"装饰元素"。这提醒启明科技：产品界面的美观程度本身就是 marketing 资产——投资于产品的 UI 设计，就是在投资于 marketing。

3. **绿色在 B2B 中的差异化**：在蓝色主导的企业软件世界中，绿色是强烈的差异化信号。它传递"友好""开源""可持续"的情绪。如果你的产品面向中小企业或开发者社区，绿色可能是比蓝色更好的选择。

4. **按钮上的深色文字**：Supabase 的翡翠绿按钮上使用 `#171717`（近黑）文字，而不是白色。这让按钮看起来像"被点亮的表面"而不是"有颜色的贴片"——一种更高级的材质感。
