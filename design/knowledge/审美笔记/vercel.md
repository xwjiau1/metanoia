# Vercel 心动设计拆解

## 第一眼感受

Vercel 的界面给人一种"未来的设计工作室"的感觉。纯白的画布上，近黑的文字（`#171717`）干净利落，偶尔出现的蓝色（`#0070f3`）像是一个精确的光标指示。最让人心动的是它的产品展示方式——没有花哨的插画，没有抽象的 3D 图形，只有真实的 UI 截图，被精心地摆放在页面上，像是一个设计师的作品集。Geist 字体有一种独特的"技术优雅"——它既不像 Helvetica 那样冰冷，也不像圆体那样休闲，而是恰到好处地处在"专业"和"亲切"之间。

## 色彩策略

**主色：Tech Blue `#0070f3`**

Vercel 的蓝色不是普通的蓝色。它饱和度适中，亮度适中，在白色背景上既不刺眼也不暗淡。这个蓝色被精准地用于"点击这里"的提示——按钮、链接、状态指示。蓝色的"科技"语义在这里被完美利用：开发者看到蓝色会想到"交互""链接""可点击"。

**近黑文字：`#171717`**

不是纯黑（`#000000`），而是接近黑的深灰。在白色背景上，纯黑会产生一种过于强烈的对比，而 `#171717` 恰到好处地柔化了文字的边缘，让长文本阅读更舒适。这种"近黑"策略是现代数字排版的标准做法。

**情绪定位：精准的技术美学 + 可信赖的开发者工具**。Vercel 的色彩传递的情绪是"专业""精确""高效"—— exactly what a developer platform needs.

## 排版策略

**字体选择逻辑：**
- **Display / UI**：Geist — Vercel 自己设计的字体家族。Geist 的特点是几何感强但又不失人文温度，笔画末端略带圆角，给人一种"精密仪器"的感觉。它的数字和代码字符特别漂亮（等宽版本的 Geist Mono 是业界公认最美观的编程字体之一）。
- **Fallback**：Inter, system-ui。

**字号层级与呼吸感：**
- Hero 区域使用超大字号（64-80px），字重适中（500-600），配合紧凑的字间距，形成强烈的视觉冲击。
- 正文 16px，行高 1.5-1.6，段落间距舒适。
- Vercel 的排版有一个特点：**标题很大，正文很清晰，中间没有太多"中号字"**。这种两极分化让层级极其清晰。

**呼吸感：** 大量的留白 + 大号标题 + 产品截图的呼吸空间。Vercel 的页面像是一个"画廊"——每个区块都有自己的空间，互不干扰。

## 空间策略

**留白节奏：** 极其慷慨的留白。Vercel 的首页常常有一半是空白——这不是浪费空间，而是在让产品截图"呼吸"。留白也是品牌语言的一部分："我们的工具足够好，不需要用装饰填满页面。"

**信息密度：** 中低密度。页面通常由几个"大块"组成，每个大块聚焦一个功能点，配以产品截图和简短文案。

**视觉焦点：** 产品 UI 截图是绝对的视觉主角。Vercel 的页面上常常出现精心制作的产品界面截图，带有微妙的光泽和投影。这些截图本身就很美——深色终端界面、代码高亮、状态指示——它们既是内容也是装饰。

## 可借鉴到启明项目的点

1. **产品截图即设计**：如果你的产品是工具型 SaaS，与其花大价钱做 3D 插画，不如投资在产品 UI 截图的美化上。一个好看的 dashboard 截图胜过千言万语。

2. **定制字体的品牌溢价**：Vercel 设计了自己的字体（Geist），这让品牌辨识度大幅提升。启明科技可以考虑是否有必要定制一款品牌字体，或者至少选择一款不那么"常见"的字体。

3. **白底黑字的极致优化**：不要低估 `#171717` 在 `#ffffff` 上的效果。调整文字的灰度值，让正文不刺眼、标题有力量，这是每个设计系统都应该做的基本功。

4. **开发者工具的设计语言**：Vercel 的设计语言是"为开发者而设计"——干净、快速、无干扰。启明科技的 B2B / 工具型产品可以借鉴这种"不打扰"的设计哲学。
