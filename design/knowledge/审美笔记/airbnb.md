# Airbnb 心动设计拆解

## 第一眼感受

Airbnb 的界面像是一次温暖的拥抱。纯白的画布上，Rausch 粉（`#ff385c`）像一团热情的火焰，而圆润的 pill 形状无处不在——搜索栏是 pill，按钮是 pill，卡片是圆角，甚至连分类标签也是 pill。手写的图标和"NEW"徽章让界面充满了人情味。这不是一个冰冷的预订机器，而是一个"有人情味的社区"。Airbnb Cereal 字体的圆润笔画与整个界面的圆润几何完美呼应，创造出一种统一的"友好感"。

## 色彩策略

**主色：Rausch `#ff385c`**

这个粉色-珊瑚色是 Airbnb 的品牌灵魂。它热情但不侵略，友好但有力量。Rausch 粉的名字来自 Airbnb 创始初期的公寓地址（Rausch Street），这赋予了颜色一个真实的故事——它不只是"选了一个好看的粉色"，而是"从真实世界中来的颜色"。

**文字色：`#222222`**

同样是近黑而非纯黑，配合纯白背景，创造出清晰但不刺眼的阅读体验。

**语义色彩：**
- **Luxe**（`#460479`）：高端房源的紫色标识
- **Plus**（`#92174d`）：精选房源的酒红色

这些语义颜色只在特定场景出现，不干扰主色的纯粹性。

**情绪定位：热情好客 + 社区温暖**。Rausch 粉传递"欢迎""热情""家的感觉"，白色传递"干净""信任"，圆润形状传递"友好""无威胁"。

## 排版策略

**字体选择逻辑：**
- **全系统**：Airbnb Cereal VF（可变字体）——这是 Airbnb 定制的字体，基于 Circular 改造。特点是字母形状圆润、开放，没有尖锐的角，与整个品牌的"友好"定位完美契合。
- **字重使用**：Display 用 500-700，但避免了过重的字重。Airbnb 的信条是"相信摄影和留白，而非排版的肌肉"。

**字号层级与呼吸感：**
- display-xl: 28px / weight 700（注意：相对保守的 display 尺寸）
- display-lg: 22px / weight 500 / letter-spacing -0.44px
- body-md: 16px / weight 400 / line-height 1.5

Airbnb 的 display 尺寸刻意保守——28px 作为最大标题，这在 SaaS 产品中算很小的。这反映了 Airbnb 的设计哲学：**摄影才是主角，文字只是辅助**。

**呼吸感：** 大量留白 + 大圆角 + 温暖色调 = 极其放松的呼吸感。Airbnb 的界面不会让你感到"紧迫"或"催促"，它的节奏是"慢慢来，找到属于你的地方"。

## 空间策略

**留白节奏：** 慷慨但有目的。首页的搜索栏是巨大的 pill 形状，占据了显著的中心位置——这是 Airbnb 的核心交互入口。房源卡片之间有清晰的间距，但不会浪费空间。

**信息密度：** 中高密度（对于 marketplace 而言）。Airbnb 需要展示大量房源信息（图片、价格、评分、位置），因此卡片布局紧凑。但圆润的边角和温暖的颜色让高密度不显压迫。

**视觉焦点：** 房源摄影是绝对的焦点。Airbnb 的卡片设计中，图片占据 60-70% 的面积，文字信息紧凑地排列在下方。Rausch 粉的价格和评分星星吸引点击。

## 可借鉴到启明项目的点

1. **圆润几何的友好力量**：Airbnb 证明了"圆角"不只是装饰，它是品牌性格的载体。如果你的产品面向消费者而非企业用户，考虑让圆角更大（14-32px）、让形状更 pill-like。

2. **"摄影/内容优先"的排版策略**：Airbnb 的标题字号相对保守（最大 28px），因为它知道用户来看的是房源照片，不是标题。启明项目可以思考：用户的真正焦点是什么？把最大的视觉权重给那个东西。

3. **颜色的故事性**：Rausch 粉有真实的故事（创始地址）。启明科技的品牌色是否也有故事？如果有，把它讲出来，颜色会因此更有力量。

4. **手写字体和图标的人情味**：Airbnb 使用手绘风格的图标和"NEW"徽章，这些小细节传递了"有人在背后"的感觉。在启明项目中，适当的"不完美"（手绘元素、非对称布局）可以增加人情味。

5. **搜索栏作为设计中心**：Airbnb 的搜索栏是一个巨大的 pill，位于页面中心——它既是功能入口，也是视觉焦点。如果你的产品核心功能是"搜索/发现"，考虑让搜索栏成为设计的主角。
