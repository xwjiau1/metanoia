# Apple 心动设计拆解

## 第一眼感受

Apple 的网站不是网站，是一座数字博物馆。打开任何 Apple 产品页面，你看到的不是"网页"，而是一系列精心策展的"展厅"——每个产品占据一整块瓷砖区域，边缘到边缘的摄影，巨大的标题悬浮在产品上方，两个小小的蓝色药丸按钮（"了解更多""购买"）安静地等待你的点击。Apple 的设计哲学是极致的减法：没有边框，没有阴影（除了产品图片下的那一缕），没有装饰性元素。产品就是展品，界面就是墙壁。

## 色彩策略

**主色：Action Blue `#0066cc`**

Apple 的蓝色是"行为蓝"——它只有一个任务：告诉你"这里可以点击"。所有链接、所有按钮、所有交互元素共享这一个蓝色。在 Apple 的世界里，颜色不是装饰，是信号。单一的蓝色选择让交互逻辑变得极其清晰：看到蓝色 = 可以操作。

**瓷砖色彩系统：**
- **白色瓷砖**（`#ffffff`）：标准产品展示
- **羊皮纸瓷砖**（`#f5f5f7`）：稍暖的灰白色，用于需要区分的区块
- **深色瓷砖系列**（`#272729`, `#2a2a2c`, `#252527`）：近黑但不是纯黑，每种深色瓷砖之间也有微妙的色差，让深色区块不单调

**情绪定位：产品崇拜 + 极简圣殿**。Apple 的色彩策略是"让产品成为唯一的彩色"。界面本身是无色的，产品摄影是彩色的。

## 排版策略

**字体选择逻辑：**
- **Display**：SF Pro Display — Apple 自家字体，为屏幕优化而生。特点是负字间距（negative letter-spacing）带来的"紧凑感"，这是 Apple 排版的签名特征。
- **正文**：SF Pro Text — 同样负字间距，但尺寸更小，优化了屏幕可读性。

**字号层级与呼吸感：**
- hero-display: 56px / weight 600 / line-height 1.07 / letter-spacing -0.28px
- display-lg: 40px / weight 600 / line-height 1.1
- lead: 28px / weight 400 / line-height 1.14
- body: 17px / weight 400 / line-height 1.47 / letter-spacing -0.374px

Apple 的排版有一个显著特征：**字号差距很大，层级之间跳跃明显**。没有"中号标题"——要么很大（56px 产品名），要么很小（17px 正文）。这种"跳跃式层级"让每个元素都有自己的空间。

**呼吸感：** 极大的瓷砖间距 + 瓷砖内部的居中排版 = 奢侈的呼吸感。Apple 的页面是你能在互联网上找到的最"不拥挤"的页面之一。

## 空间策略

**留白节奏：** Apple 的留白可以用"奢华"来形容。每个产品瓷砖通常占据一个视口（viewport）的高度，瓷砖内部的内容（标题+副标题+按钮+产品图）垂直居中，周围是大面积的纯色空间。

**信息密度：** 极低。Apple 的信息密度可能是所有顶级网站中最低的。一个 iPhone 产品页可能有十几个瓷砖，每个瓷砖只传达一个信息。

**视觉焦点：** 产品摄影是绝对的主角。UI 元素（导航、按钮、文字）都被设计为"不可见"——它们存在，但不争夺注意力。SF Pro 的字重选择也是这个策略的一部分：Display 用 600（足够清晰但不厚重），正文用 400（安静）。

## 可借鉴到启明项目的点

1. **摄影/产品图优先的设计哲学**：如果你的产品是硬件或有实体形态，学习 Apple 的"瓷砖画廊"模式。每个产品占一个全宽区块，背景纯色，产品居中。

2. **单一交互色策略**：Apple 只用一个蓝色做所有交互指示。启明项目可以问自己：我们真的需要 5 种不同的按钮颜色吗？能否用 1-2 个颜色完成所有交互语义？

3. **负字间距的力量**：SF Pro 的负字间距（-0.28px 到 -0.374px）让标题看起来更紧凑、更有力量。在启明项目的大标题中尝试收紧 letter-spacing，效果会出乎意料。

4. **深色瓷砖的色差游戏**：Apple 的深色区块使用了三种不同的近黑色（`#272729`, `#2a2a2c`, `#252527`），这让深色页面有了微妙的层次。启明项目的暗色模式可以考虑使用 2-3 种不同的深色，而不是一个纯黑。

5. **"界面消失"的设计追求**：Apple 的终极目标是让用户忘记界面的存在，只看到产品。这种"透明设计"哲学值得启明科技深思：我们的界面是否"太存在感"了？
