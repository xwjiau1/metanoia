## 第一眼感受

**"像站在发射塔下，仰望星空——极致的黑，极简的白，唯一的色彩是远方的夕阳。"**

xAI 的设计是「马斯克式」的极致减法。`#0a0a0a` 画布、`#ffffff` 文字、唯一的色彩事件是夕阳橙 `#ff7a17` 和暮色紫 `#7c3aed`。这不是一个「友好的」界面，这是一个「宇宙级的」界面——它让你感觉自己正在参与某个宏大的未来计划。

---

## 色彩策略

### 画布系统
```
画布: #0a0a0a (极致的暗)
画布软: #1a1c20 (提升)
画布卡片: #191919 (卡片)
画布中: #363a3f (边框/分隔)
```

### 文字系统
```
墨水: #ffffff (纯白)
正文: #dadbdf (微灰)
中段: #7d8187 (弱化)
弱化: #7d8187 (更弱)
```

### 强调色（极少出现）
```
Sunset: #ff7a17 (夕阳橙)
Sunset Soft: #ffc285 (柔和)
Dusk: #7c3aed (暮色紫)
Twilight: #c4b5fd (暮光)
Breeze: #a0c3ec (微风蓝)
```

这些颜色只出现在：装饰性渐变、极少数 CTA、品牌 mark。

### 色彩哲学
- 95% 的页面是黑白
- 5% 的色彩是「点缀」而非「主角」
- 这种克制传递「seriousness + 前沿」

## 排版策略

### Universal Sans
- 马斯克定制字体，几何无衬线
- 特征：干净、中性、未来感

### 字号层级（惊人地大）
```
Display XL: 96px/400/-2.4px — 巨大、轻量
Display LG: 72px/400/-1.8px
Display MD: 48px/400/-1.2px
Body LG: 18px/400/28px
Body MD: 16px/400/24px
Caption Mono: 14px/400/1.4px letter-spacing — 等宽 + 大写 + 字距加宽
```

### 排版特征
- **等宽大写标签**：14px + 等宽 + 1.4px 字距 + 全大写 — 像航天器仪表盘上的标签
- **96px 超大标题**：轻量字重（400），巨大的尺寸，但看起来不沉重
- **Weight 400 一切**：品牌从不用 bold，负字距 + 字号层级做强调

---

## 空间策略

### 极简的间距
```
xxs: 2px, xs: 4px, sm: 8px, md: 12px
lg: 16px, xl: 24px, 2xl: 32px, 3xl: 48px, 4xl: 64px
```

### 视觉焦点
- 巨大的标题是页面的主角
- 没有卡片、没有阴影、没有边框（除了 1px hairline）
- 内容直接躺在画布上

### 按钮系统
- **所有按钮都是 pill**（9999px 圆角）
- **白色半透明边框** `rgba(255,255,255,0.25)`
- 这是 xAI 的签名交互元素

## 可借鉴到启明项目的点

### 立即可用
1. **95% 黑白 + 5% 强调色**：最极端的克制，效果最强烈
2. **等宽大写标签**：14px monospace + 1.4px letter-spacing + uppercase = 科技感标签的终极形态
3. **96px 轻量大标题**：轻字重 + 巨大字号 = 未来的力量感
4. **#0a0a0a 画布**：比 `#121212` 更深，适合「前沿、神秘、宇宙」主题
5. **pill 按钮 + 半透明边框**：统一的交互形态

### 中文适配
- Universal Sans → MiSans / HarmonyOS Sans
- 等宽大写标签策略在中文中改为「等宽 + 小字号 + 灰色 + 字距加宽」
- 中文 96px 标题需要足够的行高（1.2+），否则笔画会打架

### 适合启明的项目类型
- 前沿科技、AI 实验室、太空/宇宙主题、极客产品
- 任何需要「未来感、前沿、宇宙级」气质的产品
