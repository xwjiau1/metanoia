## 使用指南

### 快速检索
```bash
# 按关键词搜索
./tools/search-design-system.sh "dark"

# 对比两个系统
./tools/compare-design-systems.sh vercel stripe

# 预览单个系统
./tools/preview-design-system.sh linear.app

# 下载到项目
./tools/download-design-system.sh linear.app ./my-project/
```

### 按项目类型选参考
1. **AI产品** → 先看 claude（温暖）, mistral.ai（优雅）, x.ai（极简）
2. **开发者工具** → 先看 vercel（精确）, linear.app（暗色高级）, supabase（开源活力）
3. **电商/展示** → 先看 apple（产品崇拜）, nike（运动能量）, airbnb（温暖邀请）
4. **金融科技** → 先看 stripe（信任+精致）, coinbase（合规）
5. **媒体/内容** → 先看 spotify（沉浸式暗色）, theverge（编辑杂志）

### 中文场景适配速查
- 衬线字体 → 替换为「思源宋体 / 方正清刻本」
- 几何无衬线 → 替换为「MiSans / HarmonyOS Sans / 阿里巴巴普惠体」
- 负字间距 → 中文减至 `-0.02em` 左右
- 大圆角 pill → 中文场景保持，增加亲切感
