## 二、推荐商业模式

### 2.1 核心策略：**开源核心 + 云服务 + 企业增值**

```
┌─────────────────────────────────────────────────────────┐
│                    产品分层架构                           │
├─────────────┬─────────────┬─────────────────────────────┤
│  开源社区版  │  云托管版   │      企业版/专业版          │
│  (获客漏斗)  │  (转化变现) │       (高客单价)            │
├─────────────┼─────────────┼─────────────────────────────┤
│ 核心 RAG    │ 云端部署    │ 本地/私有部署               │
│ 引擎 + 控制台│ 免运维     │ SSO / SAML                 │
│ 单用户/小团队│ 自动扩容   │ RBAC 细粒度权限            │
│ 社区支持    │ 优先支持   │ 专属技术支持               │
│ 基础 API    │ 高可用 SLA │ 99.9% SLA                  │
│             │ 托管向量库 │ 审计日志 / 合规             │
│             │ 协作功能   │ 定制开发 / 集成服务         │
└─────────────┴─────────────┴─────────────────────────────┘
```

### 2.2 各层详细定义

#### 开源社区版（Open Source Community Edition）

**目标**：最大化开发者采用，建立生态和口碑。

**包含功能**：
- 完整 RAG 核心引擎（文档上传、分片、嵌入、检索、生成）
- Web 控制台（单用户）
- 基础召回策略（Top-K、前后扩展）
- 单向量库（Qdrant/Chroma）
- 基础 API
- 社区支持（GitHub Issues / Discord）

**限制**：
- 单用户运行（无多用户/权限）
- 无知识库版本管理
- 无高级召回策略（多向量库并行、路由召回）
- 无错题本高级分析
- 无 SLA 保障

**许可**：Apache 2.0（允许商业使用，允许修改，允许闭源衍生）

---

#### 云托管版（Cloud Hosted）

**目标**：让不想运维的开发者/小团队快速上手。

**包含功能**：
- 开源版所有功能
- 云端免运维部署
- 多用户协作（3-20 人）
- 基础 RBAC（知识库级别权限）
- 知识库版本管理（快照/回滚）
- 托管向量库（自动扩缩容）
- 优先技术支持（邮件/工单）
- 检索日志保留 30 天

**不包含**：
- 私有部署
- SSO/SAML
- 高级审计
- 专属支持

---

#### 企业版/专业版（Enterprise Edition）

**目标**：服务有数据安全、合规、定制需求的中大型企业。

**包含功能**：
- 云托管版所有功能
- **本地/私有部署**（数据不出域）
- **SSO / SAML / LDAP**
- **细粒度 RBAC**（文档级别、操作级别）
- **审计日志**（完整操作追溯）
- **99.9% SLA**
- **专属技术支持**（微信群/飞书群/电话）
- **定制开发**（召回策略定制、集成服务）
- **培训与部署服务**
- 检索日志保留 1 年+
- 多模态 RAG（企业级）

## 三、定价策略

### 3.1 云托管版定价

参考 RAGFlow、Pinecone、Dify 等竞品定价，采用 **"免费起步 + 阶梯付费"** 模式：

| 套餐 | 价格 | 目标用户 | 规格 |
|------|------|----------|------|
| **Free** | ¥0 / $0 | 个人开发者试用 | 1 个知识库、500MB 存储、1,000 API 次/月、社区支持 |
| **Starter** | ¥99/月 或 $15/月 | 个人开发者/小项目 | 5 个知识库、5GB 存储、10,000 API 次/月、基础多用户 |
| **Pro** | ¥499/月 或 $79/月 | 中小企业技术团队 | 20 个知识库、50GB 存储、100,000 API 次/月、完整 RBAC、版本管理 |
| **Business** | ¥1,999/月 或 $299/月 | 中型企业/开发团队 | 无限知识库、200GB 存储、500,000 API 次/月、优先支持 |
| **Enterprise** | 定制报价 | 大型企业 | 私有部署、SSO、SLA、专属支持、定制开发 |

### 3.2 定价设计原则

| 原则 | 说明 |
|------|------|
| **免费层有真实价值** | Free  tier 能完成一个小型项目的完整 RAG 链路，不是"演示版" |
| **升级路径清晰** | 从 Free → Starter → Pro → Business，每个阶梯解决一个明确痛点 |
| **用量透明** | API 调用次数、存储量、知识库数，用户可以预估成本 |
| **企业版不公开标价** | 通过销售接触，根据定制需求报价，客单价空间更大 |

### 3.3 用量超额计费

| 资源类型 | 免费/包含额度 | 超额单价 |
|----------|-------------|----------|
| API 调用 | 套餐内含 | ¥0.01 / $0.0015 每次 |
| 存储空间 | 套餐内含 | ¥0.5 / $0.08 每 GB/月 |
| Embedding 推理 | 本地免费 / 云端含在套餐 | 云端超额按 GPU 时长计 |

### 3.4 企业版定价策略

**不公开标价**，采用 **"价值定价"** 模式：

- 年费制：¥5-50万/年（根据用户规模、定制需求）
- 包含：私有部署、定制开发人天、专属支持、培训
- 参考竞品：Haystack 企业支持、Dify 企业版、RAGFlow Enterprise 均在类似区间

## 五、竞品定价策略借鉴

### 5.1 Dify 模式（推荐参考）

- **社区版完全免费**，功能无限制——快速获取用户
- **云服务版**按量收费——自然转化
- **企业版**定制报价——高价值客户
- **结果**：180,000+ 开发者社区，快速增长

### 5.2 RAGFlow 模式

- **开源免费** + **云托管收费**
- 云托管定价：$29（Starter）→ $129（Pro）→ Enterprise（定制）
- 增长策略：GitHub Stars 驱动（62k+）

### 5.3 Pinecone 模式（不推荐）

- 纯 SaaS，无开源版
- 获客成本高，但收入可预测
- 不适合初创团队（需要大量营销投入）

## 七、关键定价决策

### 决策 1：开源版功能是否完整？

**推荐：开源版功能完整（核心链路无阉割）**

理由：
- 与 LangChain、Dify 等保持一致——开源版"能用"
- 限制在多用户/治理/企业功能，而非核心 RAG 能力
- 开发者不会因为"功能被砍"而抵触

### 决策 2：是否提供一次性买断？

**推荐：企业版提供买断选项**

理由：
- 中国企业偏好"买断"而非持续订阅
- 企业版买断价 = 3 年年费，赠送 1 年维护
- 云服务版保持订阅制（持续服务价值）

### 决策 3：是否支持国内模型/向量库？

**推荐：是（差异化优势）**

理由：
- 国内开发者普遍使用国产模型（通义、文心、智谱）
- 支持国内云向量库（阿里云、腾讯云、百度）
- 作为本土化优势，可适当溢价
