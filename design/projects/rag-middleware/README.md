# RAG 中间件/插件 项目

**项目代号：** RAG-Middleware
**产品定位：** 面向 Agent 应用的 RAG 插件/中间件
**负责人：** Mery（CIO，启明科技设计部）
**汇报对象：** Wenner（CEO）

---

## 项目简介

本项目旨在构建一个面向 Agent 应用的 RAG（Retrieval-Augmented Generation）基础设施中间件，通过本地 Web 控制台 + 标准 API 的方式，让开发者能够可视化地管理 RAG 全流程，包括文档摄入、智能分片、向量存储、检索召回、质量监控等环节。

核心价值：**让用户清晰看到系统中的 RAG、配置、索引等流程。**

## 关键结论

1. **市场空间充足**：RAG 整体市场 2025 年约 20-50 亿美元，预计 2030 年突破 100 亿美元。中间件/基础设施层是增速最快的子赛道之一。

2. **差异化空间明确**：当前竞品要么偏向"代码框架"，要么偏向"应用平台"，缺少"面向 RAG 运维的可视化控制台+API 层"。

3. **核心差异化（人无我有）**：
   - RAG 流程可视化控制台
   - 召回策略配置面板
   - 错题本 + 质量反馈闭环
   - 知识库治理套件
   - 多向量库热切换

4. **商业模式**：开源核心（Apache 2.0）+ 云托管版（¥99-1,999/月）+ 企业版（定制报价）

5. **实施路线图**：Phase 1 MVP（2-3月）→ Phase 2 增强（2-3月）→ Phase 3 专业版（3-4月）
