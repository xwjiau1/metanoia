## 项目概述

启明科技计划开发一套 **RAG（Retrieval-Augmented Generation，检索增强生成）智能知识库系统**，旨在帮助企业将分散的文档和知识转化为可对话、可检索的智能资产，通过大模型+向量化检索实现精准问答和知识管理。

## 项目目标

1. **核心目标**：打造一款易用的企业级知识库对话工具，让任何团队都能快速构建私有知识问答系统
2. **用户目标**：降低知识检索成本，提升信息获取效率，确保回答有据可依
3. **商业目标**：提供SaaS化服务，支持私有化部署，覆盖中小企业知识管理场景

## 项目范围

### 核心功能（V1.0）
- 文档/知识库上传与管理（支持多格式）
- 向量化检索（Embedding + Vector DB）
- 大模型对话接口（支持多轮对话）
- 引用溯源（Source Attribution）
- 用户权限管理（基础RBAC）

### 后续规划（V2.0+）
- 多模型支持（可切换不同LLM）
- 实时协作编辑
- 数据分析和洞察
- 插件化扩展
