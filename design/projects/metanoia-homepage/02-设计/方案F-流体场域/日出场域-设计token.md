# 方案 F-2 · 流体场域 — 日出场域配色

## 色彩系统

| Token | 值 | 用途 |
|-------|-----|------|
| `--canvas` | `#1a0f00` | 深棕画布 |
| `--gradient-1` | `#f97316` | 橙色 |
| `--gradient-2` | `#ef4444` | 红色 |
| `--gradient-3` | `#fbbf24` | 金色 |
| `--surface` | `rgba(255,255,255,0.06)` | 玻璃态 |
| `--surface-border` | `rgba(255,255,255,0.12)` | 玻璃边框 |
| `--ink` | `#fffbeb` | 暖白标题 |
| `--body` | `#fde68a` | 淡金正文 |
| `--muted` | `#d97706` | 暗金辅助 |

## 流体渐变

```css
background: linear-gradient(
  135deg,
  #f97316 0%,
  #ef4444 33%,
  #fbbf24 66%,
  #f97316 100%
);
background-size: 400% 400%;
animation: flow 15s ease infinite;
```

## 字体系统

与「极光场域」一致，但颜色更暖。

## 特殊效果

- 金色粒子漂浮效果
- 暖色光晕
- 日出感：从暗到明的渐变方向

## 核心页面元素

与「极光场域」结构一致，配色从紫粉蓝换成橙红金，营造日出/熔岩的温暖能量感。
