# 方案 D · 精密工坊 — 设计文档

## 设计哲学

**「像瑞士钟表一样精密」**

受 Stripe、Linear、Vercel 的设计语言启发。这不是"温暖"也不是"酷炫"，而是"可信赖的专业感"。每一个间距、每一个圆角、每一个字重都经过计算。用户打开网站的第一感受是：这家公司做事严谨、代码质量高、值得托付。

## 核心特征

- **12列网格系统**：严格对齐，像工程图纸
- **单色调 + 一个强调色**：极度克制，信息层次分明
- **小字号、高密度信息**：每屏承载更多内容，不浪费空间
- **代码片段作为装饰元素**：`monospace` 字体穿插在标题中，暗示技术基因
- **数据可视化图表融入**：用迷你折线图、柱状图替代纯文本描述
- **几何感卡片**：直角或小圆角，阴影精确到 1px

## 中文适配

| 英文原版 | 中文适配 |
|---------|---------|
| Inter / SF Mono | MiSans + JetBrains Mono（代码） |
| -0.02em 字距 | -0.03em（中文紧凑排版的极限） |
| 大写英文标签 | 10px + letter-spacing: 0.15em 中文标签 |
| 行长 65ch | 25-35个汉字 |

## 页面结构

1. **Hero** — 数据仪表盘风格，左侧大标题+右侧实时图表
2. **业务板块** — 三列数据卡片，每卡片带迷你图表
3. **项目展示** — 横向滚动时间轴，项目按时间排列
4. **运营数据** — 全宽数据墙，大数字 + 趋势线
5. **技术栈** — 网格展示技术Logo，悬停显示版本号
6. **创始人** — 极简简历，像 GitHub Profile
7. **联系我们** — 命令行风格表单
8. **Footer** — 精简链接矩阵
