# 方案 D-2 · 精密工坊 — 深海工坊配色

## 色彩系统

| Token | 值 | 用途 |
|-------|-----|------|
| `--canvas` | `#0a1628` | 深海蓝画布 |
| `--surface` | `#0d1f35` | 卡片背景 |
| `--surface-raised` | `#112945` | 悬浮面板 |
| `--ink` | `#f0f6ff` | 主标题 |
| `--body` | `#94a3b8` | 次要文字 |
| `--muted` | `#64748b` | 标签、辅助 |
| `--border` | `#1e3a5f` | 细线边框 |
| `--accent` | `#60a5fa` | 冰蓝强调 |
| `--accent-glow` | `rgba(96,165,250,0.3)` | 发光效果 |
| `--code-bg` | `#0d1f35` | 代码块 |
| `--grid` | `rgba(96,165,250,0.05)` | 网格线 |

## 特殊效果

- 背景网格线： faint blue grid overlay
- 卡片边框发光：hover 时 `#60a5fa` 外发光
- 数据图表：冰蓝色系，有霓虹感
- 光标：冰蓝色闪烁

## 核心页面元素

与石墨工坊结构一致，配色换成深海蓝调。
