# 方案 D-1 · 精密工坊 — 石墨工坊配色

## 色彩系统

| Token | 值 | 用途 |
|-------|-----|------|
| `--canvas` | `#fafafa` | 画布底色，几乎纯白 |
| `--surface` | `#ffffff` | 卡片、面板背景 |
| `--ink` | `#0a0a0a` | 主标题、正文 |
| `--body` | `#3d3d3d` | 次要文字 |
| `--muted` | `#8a8a8a` | 标签、辅助文字 |
| `--border` | `#e5e5e5` | 细线边框 |
| `--accent` | `#ea4335` | 强调色，珊瑚红 |
| `--accent-soft` | `#fce8e6` | 强调色浅背景 |
| `--code-bg` | `#f6f8fa` | 代码块背景 |
| `--success` | `#137333` | 成功状态 |
| `--warning` | `#f9ab00` | 警告状态 |

## 字体系统

| 层级 | 字体 | 字号 | 字重 | 字距 | 行高 |
|------|------|------|------|------|------|
| H1 | MiSans | 48px | 700 | -0.03em | 1.1 |
| H2 | MiSans | 32px | 600 | -0.02em | 1.2 |
| H3 | MiSans | 20px | 600 | -0.01em | 1.3 |
| Body | MiSans | 15px | 400 | 0 | 1.6 |
| Label | MiSans | 11px | 500 | 0.15em | 1.4 |
| Code | JetBrains Mono | 13px | 400 | 0 | 1.5 |

## 间距系统

基于 4px 网格：4, 8, 12, 16, 24, 32, 48, 64, 96, 128

## 圆角系统

- 卡片：8px
- 按钮：6px
- 标签：4px
- 代码块：6px

## 阴影系统

| 层级 | 值 |
|------|-----|
| 卡片 | `0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.06)` |
| 悬浮 | `0 4px 12px rgba(0,0,0,0.08)` |
| 下拉 | `0 8px 24px rgba(0,0,0,0.12)` |

## 核心页面元素

### Hero
- 两栏布局：左 55% 文字，右 45% 数据仪表盘
- 标题使用 `MiSans 48px` + `-0.03em` 字距
- 副标题 15px `#3d3d3d`
- 右侧放置一个模拟数据图表（CSS绘制迷你折线图）
- CTA 按钮：`#0a0a0a` 背景，`#fff` 文字，6px 圆角

### 业务板块
- 三列等宽卡片
- 每个卡片顶部有一个迷你数据图表（CSS）
- 卡片边框 1px `#e5e5e5`，8px 圆角
- 悬停：边框变 `#ea4335`，轻微上浮

### 项目展示
- 横向滚动时间轴
- 每个项目是一个节点，连接线贯穿
- 节点 hover 展开详情

### 运营数据
- 全宽背景 `#f6f8fa`
- 四个大数字，MiSans 64px
- 数字下方有迷你趋势图

### 创始人
- 极简风格，像 GitHub Profile 卡片
- 左侧头像，右侧信息
- 使用 monospace 字体显示"技术栈"

### AI 助手
- 右下角小方块，像终端窗口
- 展开后是一个代码编辑器风格的对话面板
- 绿色光标闪烁效果
