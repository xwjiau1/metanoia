# Metanoia AI 交互助手设计稿

## 概述

AI 助手是 Metanoia 启明科技公司主页的核心交互组件，承担三个关键角色：
1. **用户服务**：即时回答业务咨询、项目介绍、技术问题
2. **线索收集**：引导访客留下联系信息，同步给市场部（Wenner）
3. **品牌体验**：展示启明科技的 AI 技术实力，让用户直接感受 AI 能力

## 设计原则

1. **不打扰**：默认状态下最小化存在，不遮挡页面内容
2. **品牌一致**：视觉风格与所选设计方案（A/B/C）保持统一
3. **温暖高效**：对话体验既友好又专业，体现启明科技的气质
4. **渐进披露**：先展示快捷问题，再展开自由对话，降低用户决策成本

## 通用交互流程

### 入口发现
```
用户进入页面 → 右下角气泡以呼吸动画出现（延迟 3s）
├── 气泡 idle 动画：scale 1.0 → 1.05 → 1.0（周期 3s）
└── 首次访问：气泡旁弹出小提示 "有任何问题？问我！"（3s 后自动消失）
```

### 展开对话
```
点击气泡 → 对话面板展开
├── 方案A：scale(0.8) + opacity(0) → scale(1) + opacity(1)，0.3s ease-out-back
├── 方案B：opacity(0) → opacity(1)，0.2s ease-out
└── 方案C：translateY(20px) + opacity(0) → translateY(0) + opacity(1)，0.25s ease-out
```

### 对话流程
```
[欢迎消息自动出现]
"你好 👋 我是启明科技的 AI 助手。想了解我们的技术能力、查看项目案例，或直接与团队取得联系？随时问我！"

[快捷问题栏展示]
方案A：4个奶咖色圆角按钮
方案B：4个白色轮廓 pill 按钮
方案C：4个极浅灰 pill 按钮

[用户选择快捷问题 / 自由输入]
→ AI 回复（打字机效果，逐字出现，速度 30ms/字）
→ 如检测到联系意向，AI 主动引导："方便留下您的邮箱吗？我们的团队会尽快联系您。"
→ 联系信息自动同步给 Wenner（市场部）

[用户可随时关闭面板 / 最小化气泡]
```

### 退场
```
点击关闭/点击外部 → 面板关闭
├── 方案A：scale(1) → scale(0.9) + opacity(0)，0.2s
├── 方案B：opacity(1) → opacity(0)，0.15s
└── 方案C：opacity(1) → opacity(0) + translateY(10px)，0.2s
```

## 动画效果详述

### 1. 气泡呼吸动画（Idle）

```
@keyframes breathe {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.05); }
}
周期：3s
缓动：ease-in-out
```

### 2. 面板展开动画

**方案 A（温和回弹）：**
```
初始：transform: scale(0.8) translateY(20px); opacity: 0;
结束：transform: scale(1) translateY(0); opacity: 1;
duration: 300ms
缓动：cubic-bezier(0.34, 1.56, 0.64, 1) /* ease-out-back */
```

**方案 B（极简淡入）：**
```
初始：opacity: 0;
结束：opacity: 1;
duration: 200ms
缓动：ease-out
```

**方案 C（流畅滑动）：**
```
初始：transform: translateY(20px); opacity: 0;
结束：transform: translateY(0); opacity: 1;
duration: 250ms
缓动：cubic-bezier(0.25, 0.46, 0.45, 0.94)
```

### 3. 消息出现动画

```
初始：transform: translateY(16px); opacity: 0;
结束：transform: translateY(0); opacity: 1;
duration: 250ms
缓动：ease-out
stagger：连续多条消息间隔 100ms
```

### 4. 打字机效果

```
AI 回复逐字出现
速度：30ms/字符
随机抖动：±10ms（模拟真人打字的不规律性）
段落间隔：300ms 停顿
```

### 5. 快捷问题 Hover

```
方案A：
  初始：background: #efe9de; border: none;
  悬停：background: #f5f0e8; border: 1px solid #e6dfd8;
  transition: all 200ms ease;

方案B：
  初始：border-color: rgba(255,255,255,0.25);
  悬停：border-color: rgba(255,255,255,0.4);
  transition: border-color 150ms ease;

方案C：
  初始：background: #fafafa;
  悬停：background: #f5f5f5;
  transition: background 200ms ease;
```

## 技术约束

1. **性能**：面板使用 `transform` 和 `opacity` 做动画，避免触发重排
2. **无障碍**：
   - 气泡按钮有 `aria-label="打开 AI 助手"`
   - 对话面板有 `role="dialog"` + `aria-modal="true"`
   - 焦点管理：打开面板时焦点移至输入框，关闭时焦点返回气泡
   - 支持 Esc 键关闭面板
3. **响应式**：
   - 桌面：固定尺寸浮动面板
   - 手机：底部抽屉，全宽
   - 平板：固定尺寸，但更大一些（420px × 640px）
4. **持久化**：
   - 对话历史存储于 localStorage（最多保留最近 20 条）
   - 用户身份标识使用匿名 UUID

## 对接市场部（Wenner）

### 数据同步策略

```
用户对话中触发以下行为时，自动同步：
1. 用户点击 "联系创始人" 快捷问题
2. 用户主动提供邮箱/电话
3. AI 引导后用户同意留下联系方式
4. 用户表达明确的合作意向

同步内容：
- 匿名用户 ID
- 对话摘要（前 3 轮 + 最后 3 轮）
- 用户提供的联系方式（如有）
- 对话时间戳
- 用户兴趣标签（自动提取：技术/设计/AI/其他）

同步方式：
- 实时 WebSocket 推送到市场部看板
- 或每 5 分钟批量 POST 到后端 API
```
