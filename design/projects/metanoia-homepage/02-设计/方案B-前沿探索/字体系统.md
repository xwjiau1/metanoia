# 方案 B 字体系统 — 前沿探索路线

## 设计理念
参考 xAI 的「工程师化排版」— 一个干净、中性的无衬线体承担一切，Geist Mono 承担技术标签。极简到只剩本质。

## 字体家族

| 角色 | 字体 | 字重 | 备选字体栈 |
|------|------|------|-----------|
| **Display / 标题 / Body** | MiSans | 400 | HarmonyOS Sans, PingFang SC, Microsoft YaHei, sans-serif |
| **Mono / 代码 / 标签** | Geist Mono | 400 | JetBrains Mono, SFMono, monospace |

## 中文排版适配

1. **字重统一 400：** 像 xAI 一样，所有文字使用 weight 400。层级由字号和大小写区分，不由字重区分。中文 bold 在暗色背景上会显得过于厚重。
2. **字间距：** 中文 display 使用 -0.02em ~ -0.04em（比英文更保守）
3. **行高：** 中文正文 1.5-1.6（暗色背景上需要更多呼吸空间）
4. **标签策略：** 技术 eyebrow 使用 Geist Mono 大写 + 正字间距 0.1em，在暗色背景上形成 "代码注释" 感

## 排版原则

- **无风格即风格：** 字体不应该成为视觉焦点，内容才是
- **Weight 400 统一：** 品牌从不使用 bold，负字间距 + 字号层级承担强调工作
- **工程师化：** 排版清晰但不夸张，无巨大装饰性标题，无花哨字间距调整
- **GeistMono 大写 eyebrows：** 让技术标签读起来像代码注释，而非营销标签
