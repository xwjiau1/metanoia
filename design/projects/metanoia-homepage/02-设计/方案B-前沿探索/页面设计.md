# 方案 B — 前沿探索路线（参考 xAI + SpaceX）

## 色彩系统

### 设计理念
以 xAI 的极致暗色为画布，融入 SpaceX 的全出血未来感。夕阳/星空点缀象征「在黑暗中寻找光明」。这是一个为「探索者」设计的世界 — 极简、克制、充满未知的力量。

### 完整色板

| 角色 | 色名 | Hex | 情绪语义 |
|------|------|-----|----------|
| **主色** | 纯白 | `#ffffff` | 在黑暗中唯一的光 — 所有文字、按钮轮廓 |
| **主色反色** | 近黑 | `#0a0a0a` | 白色按钮上的文字 |
| **墨水** | 纯白 | `#ffffff` | 深色表面上的主文字 |
| **墨水悬停** | 象牙白 | `#fafaf7` | 悬停状态的微变 |
| **正文** | 月光灰 | `#dadbdf` | 次要文字 — 比纯白暗一度，不刺眼 |
| **弱化** | 星尘灰 | `#7d8187` | 说明文字、脚注、标签 |
| **分隔线** | 深空灰 | `#212327` | 1px 边框 — 在暗色中若隐若现 |
| **画布** | 深空黑 | `#0a0a0a` | 页面默认底色 — 近乎纯黑 |
| **柔和表面** | 夜空灰 | `#1a1c20` | 悬停状态、提示框背景 |
| **卡片表面** | 陨石灰 | `#191919` | 内容卡片背景 — 比画布略亮 |

| **暮色紫** | 深紫 | `#7c3aed` | 产品插图中的冷色点缀 |
| **暮光紫** | 淡紫 | `#c4b5fd` | 轻量级紫色强调 |
| **微风蓝** | 天空蓝 | `#a0c3ec` | 点缀蓝色 |
| **午夜蓝** | 深海蓝 | `#0d1726` | 插图背景中的最深蓝色 |
| **成功** | 星绿 | `#4ade80` | 成功状态 — 在暗色中醒目 |
| **警告** | 火星橙 | `#f59e0b` | 警告状态 |
| **错误** | 血红 | `#ef4444` | 错误状态 |
| **星空渐变** | 宇宙 | `#0a0a0a → #0d1726 → #1a1c20` | Hero 背景 — 深邃星空感 |
| **夕阳渐变** | 黄昏 | `#ff7a17 → #ffc285 → #0a0a0a` | 装饰性点缀渐变 |

### 色彩使用规则

**表面节奏：**
```
深空黑画布 → 陨石灰卡片 → 深空黑画布 → 午夜蓝深区 → 深空黑画布 → 陨石灰 Footer
```
- 整个页面以暗色为绝对主导，浅色区域仅作为 "光" 的隐喻出现
- 白色仅用于：文字、按钮轮廓、关键信息
- 夕阳/暮色色系仅出现在：产品插图、装饰性 SVG、数据图表中
- 所有交互元素使用 pill 形状（9999px 圆角）+ 半透明白色边框

**对比度：**
- 纯白(#ffffff) + 深空黑(#0a0a0a)：21:1 ✅（最高级别）
- 月光灰(#dadbdf) + 深空黑：12:1 ✅
- 星尘灰(#7d8187) + 深空黑：4.8:1 ✅（刚好通过 AA）

## 字体系统

### 字体选择逻辑

参考 xAI 的「工程师化排版」— 一个干净、中性的无衬线体承担一切，Geist Mono 承担技术标签。

| 角色 | 字体 | 备选字体栈 |
|------|------|-----------|
| **Display / 标题** | MiSans | HarmonyOS Sans, PingFang SC, Microsoft YaHei, sans-serif |
| **Body / 正文** | MiSans | HarmonyOS Sans, PingFang SC, Microsoft YaHei, sans-serif |
| **Mono / 代码标签** | Geist Mono | JetBrains Mono, SFMono, monospace |

### 字号层级

| Token | 字号 | 字重 | 行高 | 字间距 | 使用场景 |
|-------|------|------|------|--------|----------|
| `display-xl` | 64px | 400 | 1.0 | -0.04em | Hero 大标题 — 极简有力 |
| `display-lg` | 48px | 400 | 1.05 | -0.03em | 区块标题 |
| `display-md` | 36px | 400 | 1.1 | -0.02em | 子区块标题 |
| `display-sm` | 28px | 400 | 1.2 | -0.01em | 卡片标题 |
| `body-lg` | 18px | 400 | 1.6 | 0 | 引导段落 |
| `body-md` | 16px | 400 | 1.5 | 0 | 正文默认 |
| `body-sm` | 14px | 400 | 1.5 | 0 | 脚注、次要信息 |
| `caption-mono` | 12px | 400 | 1.4 | 0.1em | 大写技术标签、 eyebrows |
| `code` | 13px | 400 | 1.6 | 0 | 代码块 |
| `nav-link` | 14px | 400 | 1.4 | 0 | 导航链接 |
| `button` | 14px | 400 | 1.4 | 0 | 按钮文字 |

### 中文排版适配

1. **字重统一 400：** 像 xAI 一样，所有文字使用 weight 400。层级由字号和大小写区分，不由字重区分。中文 bold 在暗色背景上会显得过于厚重。
2. **字间距：** 中文 display 使用 -0.02em ~ -0.04em（比英文更保守）
3. **行高：** 中文正文 1.5-1.6（暗色背景上需要更多呼吸空间）
4. **标签策略：** 技术 eyebrow 使用 Geist Mono 大写 + 正字间距 0.1em，在暗色背景上形成 "代码注释" 感

## Hero 区域设计

### 布局结构
```
全出血背景 (深空黑 #0a0a0a)
├── 星空粒子/渐变效果 (Canvas/WebGL，极低透明度)
│
├── 顶部导航 (Sticky, 深空黑背景, 纯白文字)
│
├── Hero 内容区 (居中单列)
│   ├── 技术 eyebrow (Geist Mono, 12px, 大写, 正字间距, 星尘灰)
│   │   "METANOIA TECHNOLOGY / BORN FROM THE AI ERA"
│   ├── 大标题 (MiSans 64px, weight 400, 纯白)
│   │   "探索未知"
│   │   "创造可能"
│   ├── 副标题 (MiSans 18px, 月光灰)
│   │   "在黑暗中寻找光明，用代码和创意重新定义边界"
│   ├── CTA 按钮组
│   │   ├── 主按钮："了解我们" (pill 轮廓按钮, 1px 白色半透明边框 rgba(255,255,255,0.25), 透明背景, 白色文字)
│   │   └── 次按钮："联系我们" (同上，pill 轮廓)
│   └── 装饰：底部中央细线 1px #212327 + 向下箭头 (星尘灰, 呼吸动画)
│
└── 右侧装饰：夕阳色渐变光晕 (SVG radial gradient, opacity 8%, 固定位置)
```

### 视觉特征
- **背景：** 纯深空黑 `#0a0a0a`，无纹理，无渐变覆盖（除非使用 WebGL 星空效果）
- **星空效果：** 使用 Canvas 绘制微弱粒子，opacity 15%，颜色为纯白和微风蓝。粒子缓慢漂移，模拟星空。不喧宾夺主。
- **夕阳光晕：** 右下角一个 400px 的 radial gradient，从日落橙 `#ff7a17` 到透明，opacity 8%。象征「黑暗中的光」。
- **排版特征：** 大标题使用 aggressive 负字间距，紧凑有力。每行单独成句，不换行符。

## AI 助手入口设计

- 文字："Ask AI" (Geist Mono, 12px, 大写, 白色)
