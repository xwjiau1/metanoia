# 方案 A — 温暖人文路线（参考 Claude + Runway）

## 色彩系统

### 设计理念
以 Claude 的温暖奶油画布为基底，融入 Runway 的电影级暗色对比，传递「重生/温暖」气质。从暗到明的渐变呼应「重生」—— 在黑暗中诞生，走向光明。

### 色彩使用规则

**表面节奏 (Pacing)：**
```
奶油画布 → 奶咖卡片 → 深炭蓝演示 → 奶油画布 → 珊瑚号召区 → 深炭蓝 Footer
```
- 每个区块交替使用不同表面，避免连续两个区块使用同一种表面
- 珊瑚色仅用于：主CTA按钮、全出血号召卡片、品牌标记
- 暗色表面仅用于：产品演示、代码块、Footer

**对比度要求：**
- 暖墨黑(#141413) + 奶油白(#faf9f5)：对比度 15.8:1 ✅
- 珊瑚(#cc785c) + 纯白(#ffffff)：对比度 5.2:1 ✅
- 暗色上弱化(#a09d96) + 深炭蓝(#181715)：对比度 5.1:1 ✅

## 字体系统

### 字体选择逻辑

参考 Claude 的「编辑式排版」理念 — 衬线标题传递人文温度，无衬线正文保证可读性。

| 角色 | 字体 | 字重 | 备选字体栈 |
|------|------|------|-----------|
| **Display / 标题** | 思源宋体 (Noto Serif SC) | 400 / 500 | Source Han Serif SC, STSong, SimSun, serif |
| **Body / 正文** | MiSans | 400 / 500 | HarmonyOS Sans, PingFang SC, Microsoft YaHei, sans-serif |
| **Code / 代码** | JetBrains Mono | 400 | ui-monospace, SFMono, monospace |
| **Mono 标签** | Geist Mono | 400 / 500 | JetBrains Mono, monospace |

### 字号层级

| Token | 字号 | 字重 | 行高 | 字间距 | 使用场景 |
|-------|------|------|------|--------|----------|
| `display-xl` | 56px | 400 | 1.08 | -0.03em | Hero 大标题（宣言式） |
| `display-lg` | 40px | 400 | 1.12 | -0.02em | 区块标题 |
| `display-md` | 32px | 400 | 1.15 | -0.01em | 子区块标题 |
| `display-sm` | 24px | 500 | 1.25 | 0 | 卡片标题、CTA区域 |
| `title-lg` | 22px | 500 | 1.35 | 0 | 功能卡片标题 |
| `title-md` | 18px | 500 | 1.4 | 0 | 次级标题 |
| `body-lg` | 18px | 400 | 1.6 | 0 | 引导段落 |
| `body-md` | 16px | 400 | 1.6 | 0 | 正文默认 |
| `body-sm` | 14px | 400 | 1.55 | 0 | 脚注、次要信息 |
| `caption` | 12px | 500 | 1.4 | 1.2px | 标签、徽章文字 |
| `code` | 13px | 400 | 1.6 | 0 | 代码块、技术标签 |
| `nav-link` | 14px | 500 | 1.4 | 0 | 导航链接 |

### 中文排版适配要点

1. **字间距调整：** 中文大标题使用 -0.02em ~ -0.03em（相比英文的 -1.5px 更保守），避免中文笔画粘连
2. **行高调整：** 中文正文行高 1.6（比英文 1.55 略大），给中文字符更多呼吸空间
3. **最小字号：** 12px（caption），中文低于 12px 可读性急剧下降
4. **衬线标题的替代：** 思源宋体 weight 400 在屏幕上的效果与 Claude 的 Copernicus 最接近，传递相同的「编辑温度」
5. **加粗策略：** 中文不使用 bold (700)，正文用 500 表示强调 — 中文笔画复杂，700 会显得笨重

## Hero 区域设计

### 布局结构
```
全出血背景 (渐变: 深炭蓝 #181715 → 奶油白 #faf9f5, 135°)
├── 顶部导航 (Sticky, 奶油白背景, 暖墨黑文字)
│
├── Hero 内容区 (居中对齐 + 左对齐双模式)
│   ├── 顶部标签徽章 (珊瑚药丸, "Born From The AI Era")
│   ├── 大标题 (思源宋体 56px, 暖墨黑)
│   │   第一行："在黑暗中寻找光明"
│   │   第二行："我们是启明科技"
│   ├── 副标题 (MiSans 18px, 深暖灰)
│   │   "一家年轻的 AI 技术公司，用代码和创意为行业注入新生命"
│   ├── CTA 按钮组 (水平排列)
│   │   ├── 主按钮："了解我们" (珊瑚背景, 白色文字, 8px 圆角)
│   │   └── 次按钮："联系我们" (奶油白背景, 暖墨黑文字, 1px 暖米灰边框)
│   └── 装饰元素：右上角半透明珊瑚色蝴蝶 SVG 轮廓 (暗示重生)
│
└── 滚动提示：底部中央小箭头，柔和动画
```

### 视觉特征
- **渐变方向：** 从左上角的深炭蓝 `#181715` 过渡到右下角的奶油白 `#faf9f5`，角度 135°
- **纹理叠加：** 极淡的噪点纹理 (opacity 3%) 增加纸张质感
- **装饰图形：** 半透明珊瑚色蝴蝶轮廓（SVG 路径）在右上角飘浮，opacity 15%，随滚动轻微移动（视差效果）

- 滚动方向变化（向上）时：导航栏立即出现（如果之前因向下滚动隐藏）

## 响应式策略

### 断点

| 名称 | 宽度 | 关键变化 |
|------|------|----------|
| 手机 | < 768px | 汉堡导航；Hero 标题 56→32px；卡片 1-up；数据 1 列 |
| 平板 | 768–1024px | 导航横向收紧；卡片 2-up；数据 2×2；项目卡片 1-up |
| 桌面 | 1024–1440px | 完整导航；3-up 卡片；4-up 数据；2-up 项目卡片 |
| 宽屏 | > 1440px | 同桌面，外边缘更多呼吸空间；最大内容宽度锁 1200px |

### 触控目标
- 所有按钮最小 40×40px
- 导航链接 tap area 44×44px
- 卡片整个区域可点击（tap area >> 44px）
