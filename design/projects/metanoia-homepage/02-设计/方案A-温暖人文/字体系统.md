# 方案 A 字体系统 — 温暖人文路线

## 设计理念
参考 Claude 的「编辑式排版」理念 — 衬线标题传递人文温度，无衬线正文保证可读性。中文场景下，思源宋体承担 display 角色，MiSans 承担 body 角色。

## 字体家族

| 角色 | 字体 | 字重范围 | 备选字体栈 |
|------|------|----------|-----------|
| **Display / 标题** | 思源宋体 (Noto Serif SC) | 400 / 500 | Source Han Serif SC, STSong, SimSun, serif |
| **Body / 正文** | MiSans | 400 / 500 | HarmonyOS Sans, PingFang SC, Microsoft YaHei, sans-serif |
| **Code / 代码** | JetBrains Mono | 400 | ui-monospace, SFMono, monospace |
| **Mono 标签** | Geist Mono | 400 / 500 | JetBrains Mono, monospace |

## 中文排版适配要点

1. **字间距调整：** 中文大标题使用 -0.02em ~ -0.03em（相比英文的 -1.5px 更保守），避免中文笔画粘连
2. **行高调整：** 中文正文行高 1.6（比英文 1.55 略大），给中文字符更多呼吸空间
3. **最小字号：** 12px（caption），中文低于 12px 可读性急剧下降
4. **衬线标题的替代：** 思源宋体 weight 400 在屏幕上的效果与 Claude 的 Copernicus 最接近，传递相同的「编辑温度」
5. **加粗策略：** 中文不使用 bold (700)，正文用 500 表示强调 — 中文笔画复杂，700 会显得笨重
6. **Display 字重：** 衬线标题始终使用 400（regular），never bold。负字间距是品牌特征的一部分

## 排版原则

- **衬线 + 无衬线的编辑式对话：** 思源宋体的笔画粗细变化让标题有「呼吸感」和「节奏感」，像是在阅读一篇写得很好的散文
- **跳级策略：** 界面很少出现"中等字号"——要么很大（标题），要么很小（正文和 metadata），创造清晰的视觉层级
- **呼吸感：** 大标题与小正文之间形成强烈的尺度对比，但过渡自然

## 字体加载策略

```css
/* 思源宋体 - 从 Google Fonts /  Adobe Fonts 加载 */
@import url('https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@400;500&display=swap');

/* MiSans - 从小米 CDN 加载 */
@font-face {
  font-family: 'MiSans';
  src: url('https://cdn.jsdelivr.net/npm/misans@4.0.0/Regular/MiSans-Regular.woff2') format('woff2');
  font-weight: 400;
}
@font-face {
  font-family: 'MiSans';
  src: url('https://cdn.jsdelivr.net/npm/misans@4.0.0/Medium/MiSans-Medium.woff2') format('woff2');
  font-weight: 500;
}

/* JetBrains Mono */
@import url('https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400&display=swap');
```
