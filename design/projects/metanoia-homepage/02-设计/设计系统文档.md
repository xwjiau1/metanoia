## 一、设计系统概述

本设计系统为三套设计方案（A/B/C）提取共用设计 tokens，并提供从选定方案到开发落地的完整 token 映射。

**三套方案定位：**

| 方案 | 名称 | 核心气质 | 参考系统 |
|------|------|----------|----------|
| A | 温暖人文 | 重生/温暖 | Claude + Runway |
| B | 前沿探索 | 探索/前沿 | xAI + SpaceX |
| C | 多彩活力 | 年轻/活力 | Figma + Vercel |

## 二、共用的 Design Tokens

### 2.1 基础单位

所有方案共用 **4px** 作为间距基础单位。所有 spacing、radius 值均为 4px 的倍数。

### 2.2 中文排版基线

| 维度 | 规则 |
|------|------|
| 最小字号 | 12px（caption），中文低于此值可读性急剧下降 |
| 正文行高 | 1.5–1.6（比英文 1.4–1.55 略大） |
| 标题字间距 | -0.02em ~ -0.03em（中文，比英文保守） |
| 正文字间距 | 0（中文不需要负字间距） |
| 加粗策略 | 正文使用 500 表示强调，不使用 700 |
| 衬线标题 | 方案 A 使用思源宋体 400/500，never bold |

### 2.3 字体栈（中文适配）

```
/* 标题字体 - 方案 A */
--font-display: "Noto Serif SC", "Source Han Serif SC", "STSong", "SimSun", serif;

/* 正文字体 - 三方案共用 */
--font-body: "MiSans", "HarmonyOS Sans", "PingFang SC", "Microsoft YaHei", sans-serif;

/* 代码/等宽字体 - 三方案共用 */
--font-mono: "Geist Mono", "JetBrains Mono", ui-monospace, SFMono-Regular, monospace;

/* 加载策略 */
font-display: swap;
```

**字体加载源：**
- MiSans：小米 CDN（`https://cdn.jsdelivr.net/npm/misans@4.0.0/...`）
- Noto Serif SC：Google Fonts
- Geist Mono：Vercel Font CDN / Google Fonts

### 2.4 响应式断点（三方案共用）

| Token | 宽度 | 关键变化 |
|-------|------|----------|
| `sm` | < 640px | 手机端最小布局 |
| `md` | 640–768px | 手机→平板过渡 |
| `lg` | 768–1024px | 平板端布局 |
| `xl` | 1024–1280px | 桌面端布局 |
| `2xl` | 1280–1440px | 宽屏布局 |
| `3xl` | > 1440px | 超宽屏布局 |

### 2.5 触控目标（三方案共用）

| 元素 | 最小尺寸 |
|------|----------|
| 按钮 | 40 × 40px（桌面）/ 44 × 44px（触控） |
| 图标按钮 | 36px（桌面）/ 44px（触控） |
| 输入框 | 40px 高度 |
| 卡片 | 整个区域可点击 |
| 导航链接 | 44 × 44px tap area |

## 五、中文适配方案

### 5.1 字体替换映射

| 原设计系统字体 | 中文替换字体 | 替换理由 |
|---------------|-------------|----------|
| Copernicus / Tiempos Headline | 思源宋体 (Noto Serif SC) | 最接近的屏幕衬线体，传递编辑温度 |
| StyreneB / Inter (body) | MiSans | 专为中文优化的几何无衬线体 |
| Universal Sans | MiSans | 中性几何无衬线，适合工程师气质 |
| figmaSans | MiSans | 几何无衬线，支持 fine-grained weight |
| Geist | MiSans | 几何精确，中文 counterpart |
| Geist Mono | Geist Mono | 等宽字体，中英文混排友好 |

### 5.2 排版参数调整

| 参数 | 英文原始值 | 中文调整值 | 调整理由 |
|------|-----------|-----------|----------|
| Display letterSpacing | -1.5px (英文) | -0.03em (中文) | 中文字符过紧会粘连 |
| Body lineHeight | 1.55 (英文) | 1.6 (中文) | 中文字符需要更多呼吸空间 |
| 最小字号 | 11px (英文) | 12px (中文) | 中文笔画复杂，低于 12px 可读性差 |
| Bold weight | 700 (英文) | 500 (中文) | 中文笔画多，700 显得笨重 |
| 标题 fontWeight | 400 (Claude serif) | 400/500 (思源宋体) | 保持衬线优雅 |
| 大写 eyebrows | 英文 uppercase | 中文正常大小写 | 中文无大小写，用 Mono + 字间距替代 |

### 5.3 组件尺寸调整

| 组件 | 英文系统值 | 中文调整值 | 调整理由 |
|------|-----------|-----------|----------|
| 按钮高度 | 32-36px | 40px | 中文按钮文字需要更大触控面积 |
| 输入框高度 | 32px | 40-48px | 中文字符输入需要更大空间 |
| 卡片 padding | 24px | 32px | 中文段落更长，需要更多内部空间 |
| 导航高度 | 56px | 56-64px | 中文导航链接需要足够高度 |
| 气泡尺寸 | 48px | 56px | 中文 "AI" 标签需要更大空间 |
