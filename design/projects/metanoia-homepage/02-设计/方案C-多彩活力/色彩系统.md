# 方案 C 色彩系统 — 多彩活力路线

## 设计理念
以 Vercel 的白色精确画布为基底，融入 Figma 的多彩 pastel 色块策略。每一个故事区块由一个饱和 pastel 面板承载，传递「年轻/活力」气质。白色是编辑画布，颜色是故事。

## 色彩使用规则

### 表面节奏
```
白色 Hero → 网格渐变装饰 → 白色功能说明 → 青柠绿系统区块 → 深靛蓝产品区块 → 珊瑚项目区块 → 白色模板网格 → 白色 Footer
```

- **白色画布** 是默认状态，占页面 60% 以上面积
- **Pastel 色块** 不是点缀，是完整的区块背景 — 每个色块占据一个完整 viewport 的垂直空间
- **两个色块之间必须有白色画布隔开** — Figma 的硬性规则
- **网格渐变** 仅用于 Hero 背景的装饰性氛围，不缩小到图标级别
- **极墨黑** 仅用于真正的 CTA 和选中状态，不作为装饰色
- **促销粉** 每页最多使用一次

### 对比度
- 极墨黑(#171717) + 白色(#ffffff)：16:1 ✅ AAA
- 极墨黑 + 青柠绿(#dceeb1)：12:1 ✅ AAA
- 白色 + 深靛蓝(#1f1d3d)：14:1 ✅ AAA

### Do's and Don'ts
- ✅ 将极墨黑保留给真正的 Primary CTA 和选中状态
- ✅ 引入故事区块时，从 pastel 色块家族中选择 **一个** 色块
- ✅ 每个 CTA 使用 pill 形状（100px 圆角），每个图标按钮使用圆形
- ✅ 每两个色块之间让页面回到白色画布
- ❌ 不使用中灰色文字 — 正文层级由 weight 而非 opacity 承载
- ❌ 不给色块区块添加 drop-shadow（颜色本身就是深度）
- ❌ 不在文档化的 pastel 调色板之外引入新强调色
- ❌ 不在单个 viewport 内组合超过一个色块
