# 方案 C — 多彩活力路线（参考 Figma + Vercel）

## 色彩系统

### 设计理念
以 Vercel 的白色精确画布为基底，融入 Figma 的多彩 pastel 色块策略。每一个故事区块由一个饱和 pastel 面板承载，传递「年轻/活力」气质。白色是编辑画布，颜色是故事。

### 完整色板

| 角色 | 色名 | Hex | 情绪语义 |
|------|------|-----|----------|
| **主色 (Primary)** | 极墨黑 | `#171717` | 所有 CTA、标题、核心交互 — Vercel 的 ink |
| **主色反色** | 纯白 | `#ffffff` | 黑色按钮上的文字 |

### 色彩使用规则

**表面节奏：**
```
白色 Hero → 网格渐变装饰 → 白色功能说明 → 青柠绿系统区块 → 深靛蓝产品区块 → 珊瑚项目区块 → 白色模板网格 → 白色 Footer
```

- **白色画布** 是默认状态，占页面 60% 以上面积
- **Pastel 色块** 不是点缀，是完整的区块背景 — 每个色块占据一个完整 viewport 的垂直空间
- **两个色块之间必须有白色画布隔开** — Figma 的硬性规则
- **网格渐变** 仅用于 Hero 背景的装饰性氛围，不缩小到图标级别
- **极墨黑** 仅用于真正的 CTA 和选中状态，不作为装饰色
- **促销粉** 每页最多使用一次

**对比度：**
- 极墨黑(#171717) + 白色(#ffffff)：16:1 ✅
- 极墨黑 + 青柠绿(#dceeb1)：12:1 ✅
- 白色 + 深靛蓝(#1f1d3d)：14:1 ✅

## 字体系统

### 字体选择逻辑

参考 Figma 的「单一可变字体」策略 — 一个几何无衬线体通过 weight 变化表达层级，JetBrains Mono 承担技术标签。

| 角色 | 字体 | 备选字体栈 |
|------|------|-----------|
| **Display / 标题 / Body** | MiSans | HarmonyOS Sans, PingFang SC, Microsoft YaHei, sans-serif |
| **Mono / 代码 / 标签** | Geist Mono | JetBrains Mono, SFMono, monospace |

### 字号层级

| Token | 字号 | 字重 | 行高 | 字间距 | 使用场景 |
|-------|------|------|------|--------|----------|
| `display-xl` | 56px | 500 | 1.05 | -0.03em | Hero 大标题 |
| `display-lg` | 40px | 500 | 1.1 | -0.02em | 区块标题 |
| `display-md` | 32px | 500 | 1.15 | -0.01em | 卡片集群标题 |
| `headline` | 24px | 500 | 1.35 | -0.01em | 色块内故事标题 |
| `subhead` | 24px | 400 | 1.35 | -0.01em | 引导段落（接近标题尺度） |
| `body-lg` | 20px | 400 | 1.5 | 0 | Hero 引导段落 |
| `body` | 18px | 400 | 1.5 | 0 | 正文默认 |
| `body-sm` | 16px | 400 | 1.5 | 0 | 卡片正文、Footer |
| `link` | 20px | 500 | 1.4 | 0 | 内联链接强调 |
| `button` | 16px | 500 | 1.4 | 0 | 按钮文字 |
| `eyebrow` | 14px | 400 | 1.3 | 0.05em | 大写 section eyebrows（Geist Mono） |
| `caption` | 12px | 400 | 1.4 | 0.05em | 大写 captions（Geist Mono） |
| `code` | 13px | 400 | 1.6 | 0 | 代码块 |
| `nav-link` | 14px | 500 | 1.4 | 0 | 导航链接 |

### 中文排版适配

1. **字重层级：** MiSans 使用 400/500 两档（不像 Figma 那么细粒度的 320/330/340）
2. **负字间距：** display 使用 -0.02em ~ -0.03em，body 保持 0
3. **行高：** 中文 display 1.05-1.15，body 1.5（比英文 1.4 略大）
4. **Mono 仅用于 eyebrows 和 captions：** Geist Mono 大写 + 正字间距，不用于正文
5. **按钮 pill：** 100px 圆角 — Figma 的品牌形状，中文场景下保持，增加亲和力

## Hero 区域设计

### 布局结构
```
全出血背景 (极浅灰 #fafafa)
├── 网格渐变氛围背景 (多色 mesh gradient: 科技蓝→薄荷青→深紫→亮粉, 仅 Hero 上半区)
│
├── 顶部导航 (Sticky, 白色背景, 极墨黑文字, 56px 高度)
│
├── Hero 内容区 (居中单列)
│   ├── 小 mono eyebrow (Geist Mono, 14px, 大写, 银灰)
│   │   "METANOIA — BORN FROM THE AI ERA"
│   ├── 大标题 (MiSans 56px, weight 500, 极墨黑, 负字间距)
│   │   "年轻，探索，重生"
│   │   "这就是启明科技"
│   ├── 副标题 (body-lg, 中灰)
│   │   "用代码和创意为行业注入新生命"
│   ├── CTA 按钮组
│   │   ├── 主按钮："了解我们" (pill 100px 圆角, 极墨黑背景, 白色文字)
│   │   └── 次按钮："联系我们" (pill, 白色背景, 极墨黑文字)
│   └── 产品截图/抽象图形展示 (圆角 16px, 多层堆叠阴影)
│
└── 客户 Logo 条 (36px 高度, 极墨黑背景, 白色 logo 横向滚动)
```

### 视觉特征
- **网格渐变：** 多色 mesh gradient (cyan→blue→magenta→amber) 作为 Hero 上半区的氛围背景。使用 SVG 或 Canvas 渲染，不裁剪、不平铺、不缩小到图标。
- **产品展示：** 3 张产品截图以堆叠卡片形式展示（轻微旋转 + 偏移），带堆叠阴影。
- **Logo 条：** 极墨黑背景的水平滚动条，展示客户/合作伙伴 logo（单色处理）。
