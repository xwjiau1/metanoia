## 4. 用户故事

### US-1：企业决策者浏览官网
> **作为** 一位中小企业创始人，
> **我想** 在 3 分钟内了解启明科技的技术能力和项目案例，
> **以便** 评估是否适合我的业务需求。

**验收标准：**
- 首页首屏清晰展示公司定位和价值主张
- 项目展示板块有具体的项目截图和简介
- 可以快速找到联系方式或发起对话

### US-2：技术爱好者探索项目
> **作为** 一名前端开发者，
> **我想** 查看启明科技的开源项目和技术栈，
> **以便** 学习参考或贡献代码。

**验收标准：**
- 每个项目卡片都有 GitHub 链接
- 技术栈标签清晰列出使用的技术
- 项目截图/演示展示实际效果

### US-3：访客通过 AI 助手咨询
> **作为** 一位对 AI 服务感兴趣的访客，
> **我想** 通过 AI 助手快速了解启明科技的服务，
> **以便** 在不填写表单的情况下获得初步信息。

**验收标准：**
- AI 助手能回答关于服务的基本问题
- 对话体验流畅，回复时间在 3 秒内
- 如有合作意向，AI 能引导留下联系方式

### US-4：市场部接收线索
> **作为** 市场部负责人 Wenner，
> **我想** 收到潜在客户通过官网提交的咨询，
> **以便** 及时跟进商机。

**验收标准：**
- 联系表单提交后，Wenner 收到邮件/通知
- AI 助手对话中如用户留下联系方式，自动同步
- 线索包含用户兴趣标签和对话摘要

### US-5：移动端访问
> **作为** 一位在通勤途中用手机浏览的访客，
> **我想** 在手机上获得与桌面端一致的信息和体验，
> **以便** 随时了解启明科技。

**验收标准：**
- 移动端排版正确，无水平滚动
- 触控目标 ≥ 44px
- 表单在手机上易于填写

## 6. 验收标准

### 6.1 功能验收

| # | 验收项 | 通过标准 |
|---|--------|----------|
| 1 | 首页加载 | 首屏内容在 3 秒内可见；LCP（最大内容绘制）≤ 2.5s |
| 2 | 导航功能 | 所有导航链接可点击，平滑滚动到对应区块；锚点 URL 可分享 |
| 3 | 响应式 | 桌面(≥1024px)、平板(768-1024px)、手机(<768px) 三端无布局错乱 |
| 4 | 联系表单 | 姓名/邮箱/需求三字段必填；邮箱格式验证；提交后显示成功提示 |
| 5 | AI 助手 | 气泡可点击展开；欢迎消息正常；快捷问题可触发 AI 回复 |
| 6 | 项目链接 | 所有 GitHub 链接可点击，跳转正确 |
| 7 | 社交链接 | GitHub/LinkedIn/Email 链接可点击，跳转正确 |
| 8 | 图片加载 | 所有图片正常显示，懒加载工作正常，无 404 |

### 6.2 设计验收

| # | 验收项 | 通过标准 |
|---|--------|----------|
| 1 | 色彩一致性 | 所有颜色使用设计系统定义色值，无随意新增颜色 |
| 2 | 字体一致性 | 标题/正文使用指定字体栈，无系统默认字体泄露 |
| 3 | 间距一致性 | 所有间距使用设计系统 tokens，无随意像素值 |
| 4 | 圆角一致性 | 按钮/卡片/输入框圆角符合设计规范 |
| 5 | 动画一致性 | 动画使用设计系统定义参数，无突兀或不一致的动效 |
| 6 | 无障碍 | 颜色对比度 ≥ AA 标准；图片有 alt 文本；焦点状态可见 |

### 6.3 性能验收

| 指标 | 目标 | 测量工具 |
|------|------|----------|
| Lighthouse Performance | ≥ 80 | Chrome DevTools |
| First Contentful Paint (FCP) | ≤ 1.8s | Chrome DevTools |
| Largest Contentful Paint (LCP) | ≤ 2.5s | Chrome DevTools |
| Time to Interactive (TTI) | ≤ 3.8s | Chrome DevTools |
| Cumulative Layout Shift (CLS) | ≤ 0.1 | Chrome DevTools |
| 首屏 JS 大小 | ≤ 200KB (gzip) | webpack-bundle-analyzer |

## 7. 技术约束

### 7.1 前端技术栈

| 层级 | 推荐方案 | 备选方案 | 决策理由 |
|------|----------|----------|----------|
| 框架 | Next.js 14 (App Router) | Nuxt.js / 纯 HTML | React 生态成熟；SSR 利于 SEO；Irra 熟悉 |
| 样式 | Tailwind CSS | CSS Modules / Styled Components | 与设计系统 tokens 天然契合；开发效率高 |
| 动画 | Framer Motion | GSAP / 纯 CSS | React 生态；声明式 API；AI 助手动画友好 |
| 字体 | @font-face + font-display: swap | 系统字体栈 | 确保中文字体正确加载 |
| 图标 | Lucide React | Heroicons / 自定义 SVG | 轻量；Tree-shaking；风格统一 |

### 7.2 后端/API 需求（Irra 负责）

| 接口 | 方法 | 描述 | 优先级 |
|------|------|------|--------|
| `/api/contact` | POST | 接收联系表单数据，发送邮件给市场部 | P0 |
| `/api/chat` | POST | AI 助手对话接口，对接 LLM API | P1 |
| `/api/chat/lead` | POST | 同步对话线索给市场部看板 | P1 |
| `/api/blog` | GET | 获取最新博客文章列表 | P1 |
