- 🌱 **年轻（Youth）**：大胆色彩、动感排版、不规则布局

- 🦋 **重生（Rebirth）**：从暗到明的渐变、蜕变元素、生命力色彩

## 三方案核心差异速览

| 维度 | 方案 A（温暖人文） | 方案 B（前沿探索） | 方案 C（多彩活力） |
|------|-------------------|-------------------|-------------------|
| **画布** | 奶油白 `#faf9f5` | 深空黑 `#0a0a0a` | 纯白 `#ffffff` |
| **主色** | 珊瑚 `#cc785c` | 白色 `#ffffff` | 极墨黑 `#171717` |
| **字体** | 思源宋体 + MiSans | MiSans 统一 | MiSans + Geist Mono |
| **字重** | 400/500 | 统一 400 | 400/500 |
| **按钮** | 8px 圆角 | pill 轮廓 | 100px pill |
| **卡片** | 12px 圆角，无阴影 | 8px 圆角，hairline 边框 | 8-24px 圆角，堆叠阴影 |
| **Hero** | 暗→明渐变 + 蝴蝶装饰 | 星空粒子 + 夕阳光晕 | 网格渐变 + 产品截图堆叠 |
| **表面节奏** | 奶油→奶咖→深炭蓝交替 | 纯黑→陨石灰→午夜蓝交替 | 白色→pastel 色块→白色交替 |
| **情绪** | 温暖、人文、重生 | 极简、克制、探索 | 活力、多彩、年轻 |
| **适合** | 传递「蜕变/觉醒」的治愈感 | 传递「前沿/硬核」的技术感 | 传递「年轻/创意」的活力感 |

## 推荐方案

**Mery（设计部）推荐：方案 A — 温暖人文路线**

**推荐理由：**
1. **与品牌名契合度最高：** Metanoia 意为「蜕变、觉醒」，方案 A 的「从暗到明」渐变直接呼应这一含义
2. **差异化明显：** 市场上 AI 公司多为深色（xAI）或白色（Vercel），奶油白 + 珊瑚色的组合独一无二
3. **受众友好：** 企业决策者（主要用户）对温暖、可信的设计反应更好；过于硬核的暗色可能让非技术决策者感到距离感
4. **中文适配友好：** 思源宋体在中文屏幕上效果出色，编辑式排版对中文长文本阅读友好
5. **扩展性强：** 未来品牌扩展（产品页、博客、文档）都能在温暖画布上一致延展

**备选建议：**
- 如果 JiaWen 希望更强烈的「技术/前沿」信号 → 选择方案 B
- 如果 JiaWen 希望更强烈的「创意/活力」信号 → 选择方案 C
