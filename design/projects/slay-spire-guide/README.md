## 项目背景

《杀戮尖塔2》（Slay the Spire 2）于2026年3月5日开启Steam抢先体验，发售2周即售出460万份，峰值在线57万人，创Steam deckbuilder品类历史纪录。与此同时，StS1仍保持约1万日活。两代合计超千万玩家，中文区占比21.5%。

然而，现有攻略工具存在明显空白：
- 无中文AI实时攻略助手
- 无跨两代统一平台
- 无截图识别+即时建议能力
- 无低门槛个人对局记录工具

本项目旨在填补上述空白，打造StS中文社区的"智能攻略顾问"。

## 核心结论

1. **市场机会明确**：千万级玩家基数，中文区40万+核心用户，现有工具无直接竞品
2. **产品形态**：Web应用（桌面浏览器），方便游戏时Alt+Tab切屏使用
3. **核心差异化**：截图识别 → AI实时建议（战斗出牌、选牌、路线选择）
4. **两代兼容**：StS1数据完整先行，StS2随版本迭代补充
5. **预估周期**：MVP 8~10周，完整版 v1.0 约3.5~4个月
6. **立项建议**：✅ 推荐立项
