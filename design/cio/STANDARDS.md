# 设计部作业规范

**版本：** V1.0
**生效日期：** 2026-05-10
**适用范围：** 所有产品设计项目
**责任人：** Mery（CIO）

---

## 一、设计流程总览

```
Idea对接 → 市场调研 → 竞品分析 → 用户画像 → PRD撰写
    → 原型设计 → 交互设计 → 视觉设计 → 技术评估 → 迭代优化
```

**阶段数：** 10个标准阶段
**执行模式：** Wenner派单 → Mery执行 → Wenner审核 → JiaWen确认

---

## 二、各阶段规范

### Stage 1: Idea对接

**输入：** JiaWen的idea或Wenner的需求
**责任人：** Mery
**动作：**
- 快速理解idea核心
- 识别目标用户群体
- 初步判断市场机会大小
- 输出：Idea摘要 + 初步方向

### Stage 2: 市场调研

**责任人：** Mery
**交付物：** `01-调研/市场调研报告.md`

**必须包含：**
1. 目标市场规模（TAM/SAM/SOM）
2. 竞品清单（至少3个直接竞品）
3. 竞品优劣势对比矩阵
4. 市场趋势和用户痛点
5. 机会点分析

**数据来源要求：**
- 至少引用2个真实数据来源
- 可接受：行业报告、公开数据、用户评论分析
- 不接受：纯主观臆断

### Stage 3: 竞品分析

**交付物：** `01-调研/竞品分析报告.md`

**分析维度：**
- 功能对比（表格形式）
- 定价策略
- 用户评价分析（好评/差评关键词）
- 视觉和交互体验对比
- 差异化机会

### Stage 4: 用户画像

**交付物：** `01-调研/用户画像.md`

**内容：**
- 核心用户群体（2-3个典型 persona）
- 用户场景（使用场景、痛点、需求）
- 用户旅程地图（从发现到留存）

### Stage 5: PRD撰写

**交付物：** `02-PRD/产品需求文档.md`

**必须包含：**
1. 产品定位（一句话描述）
2. 目标用户
3. 核心功能清单（P0/P1/P2优先级）
4. 用户故事（每个P0功能至少1个）
5. 数据指标（北极星指标 + 辅助指标）
6. 非功能需求（性能、安全、兼容）

**PRD质量标准：**
- 每个功能必须有"为什么做"的解释
- 每个功能必须有验收标准
- 必须考虑异常流程和边界状态

### Stage 6: 原型设计

**交付物：** `02-PRD/原型.html` 或 Figma链接

**工具：** Figma（优先）或 HTML原型
**要求：**
- 覆盖所有P0功能流程
- 包含页面流转和交互说明
- 标注关键数据和状态
- 考虑空状态、加载状态、错误状态

### Stage 7: 交互设计

**交付物：** `03-设计/交互设计稿.fig`

**规范：**
- 遵循平台设计规范（iOS Human Interface / Material Design）
- 统一交互模式（导航、表单、反馈）
- 考虑单手操作友好
- 无障碍设计基础（字体大小、对比度）

### Stage 8: 视觉设计

**交付物：** `03-设计/视觉设计稿.fig`

**规范：**
- 设计系统：颜色、字体、间距、组件库
- 深色模式适配
- 图标风格统一
- 品牌元素融入

### Stage 9: 技术可行性评估

**责任人：** Mery发起，Irra评估
**交付物：** `04-评估/技术可行性报告.md`

**评估内容：**
- 各功能的技术实现难度（高/中/低）
- 预估开发周期
- 技术风险和替代方案
- 是否需要第三方服务

### Stage 10: 迭代优化

**责任人：** Mery
**动作：**
- 根据Irra评估调整设计
- 简化过高成本的功能
- 优化交互细节
- 输出最终定稿

## 四、质量标准

| 检查项 | 标准 |
|--------|------|
| 数据来源 | ≥ 2个真实来源 |
| 竞品数量 | ≥ 3个直接竞品 |
| PRD功能清单 | 含优先级和验收标准 |
| 设计稿完整性 | 覆盖P0所有流程 |
| 技术评估 | 必须有Irra确认 |
| 文档语言 | 中文为主，术语可用英文 |

## 五、跨部门协作

### 与Irra（技术部）的协作
- Mery出设计稿 → Irra评估技术可行性 → Mery调整 → 定稿
- 设计稿必须包含交互说明和状态标注
- 技术限制下，Mery有权简化设计，但需告知Wenner

### 与Wenner（CEO）的协作
- Mery向Wenner汇报里程碑进展
- Wenner审核PRD和设计稿
- 重大方向调整需JiaWen确认
