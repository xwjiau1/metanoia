### 文件存放规则（公司规范）

| 文件类型 | 存放位置 | 示例 |
|----------|----------|------|
| 研究报告/调研 | `knowledge/research/` | awesome-design-md研究报告.md |
| 设计拆解/分析 | `knowledge/审美笔记/` | claude.md, vercel.md |
| 工具验证报告 | `knowledge/tools/` | 工具脚本验证报告.md |
| 案例库索引 | `knowledge/design-systems/` | 分类索引.md |
| 项目PRD | `projects/{name}/01-PRD/` | 设计任务书.md, 产品需求文档.md |
| 项目设计稿 | `projects/{name}/02-设计/` | 色彩系统.md, 字体系统.md, 页面设计.md |
| 项目原型 | `projects/{name}/03-原型/` | （待产出） |
| 工具脚本 | `tools/` 或 `projects/{name}/05-构建/` | *.sh |
| 部门成立方案 | `ceo/marketing/01-成立方案/` | 市场部成立方案.md |
| 工作流程 | `ceo/marketing/02-工作流程/` | 官网咨询对接流程.md |
| 标准模板 | `ceo/marketing/03-模板/` | 市场分析报告模板.md |
| 业务介绍 | `ceo/marketing/04-业务介绍/` | 启明科技业务介绍.md |
| 项目归档 | `projects/{name}/项目归档.md` | 项目归档.md |
| 部署检查清单 | `projects/{name}/部署上线Checklist.md` | 部署上线Checklist.md |
| 交付报告 | `projects/{name}/06-交付/` | 交付报告.md |
| CTO任务记录 | `projects/{name}/irra-task.md` | irra-task.md |
